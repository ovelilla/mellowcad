This file is not auto-loaded. It has no `applyTo`. Update the affected row when you finish a feature;
do not append a narrative of the work.

Conventions used below: `missing:` lists options that exist in AutoCAD and not here. A parenthetical
gives the reason when the gap is blocked on something else rather than merely unbuilt.

## Coordinate systems

The UCS is an origin and X and Y axes in space, so its XY plane can tilt. Every object keeps a
normal (DXF 210) and, a line aside, its points in the OCS of that normal, as DXF stores them; what
is drawn in a tilted UCS takes its Z as the normal. The commands work in the UCS's XY plane.

## Arabic interface (`ar`)

`/ar/draw` is English AutoCAD with its interface in Arabic: palettes, menus, tooltips, the status bar
and the language menu speak Arabic and mirror right to left; the drawing, the command line, the
dynamic input, the coordinates and every technical value stay left to right.

- **Deviation, forced by what does not exist:** there is no Arabic AutoCAD — Autodesk ships 14
  languages and none is right to left — and whoever drafts in Arabic works in the English one. So
  Arabic's command language is the global one: the same names, aliases, prompts, keywords and
  canvas labels as `/draw` (`cad/locales/ar.json` holds only `interface`; `WHY` in
  `i18n/engine.ts`). An Arabic vocabulary would be one no AutoCAD user has ever seen, and would put
  bidirectional text in the command line.
- **Deviation, forced by the platform:** a Ctrl shortcut is read by its physical key (`e.code`)
  when the layout sends a letter that is not latin — with the Arabic layout Ctrl+Z arrives as
  `ئ`. Desktop accelerators, AutoCAD's included, do not depend on the layout. Typed text is taken
  as typed: `LINE` typed on the Arabic layout is an unknown command, as in AutoCAD.
- The interface words are the project's, written in Modern Standard Arabic with the glossary
  (`docs/i18n-glossary.md`). `ar` is `live` since 01/10/2026 **without a native speaker's
  review**, by the author's decision: none was available. Where one should look first, if one
  ever is: the glossary's † terms and the ViewCube's compass letters, then `messages/ar.json` and
  `cad/locales/ar.json`.
- **Missing:** drawing text in a right-to-left script. TEXT and MTEXT draw whatever is typed,
  Arabic included, but with no paragraph direction of their own (always left to right), measured
  as an average glyph (Arial's widths cover latin only), so an Arabic label's box and centring are
  approximate.

## Blocks palette

`BLOCKSPALETTE` implements the Current Drawing tab only, as a tab of the modeless palette panel:
thumbnails rendered through the real `SceneBuilder`, wildcard filter (`?` / `*`), click to INSERT,
per-block delete guarded when in use. The panel stays open while blocks are placed, so one block
after another is a click on each. Missing: Recent / Favorites / Libraries tabs, drag and drop,
context menu, icon/list toggle, and the Insertion Point / Scale / Uniform Scale / Rotation /
Auto-Placement / Repeat Placement ("prompted automatically for additional insertion points until
you press Esc") / Explode checkboxes.

## Roadmap

Agreed ordering. The rule behind it: **close model gaps before command gaps**, because every new
entity type multiplies the "Adding an entity type" checklist that a normal per entity would force
us to walk again, whereas a command costs the same before or after it.

1. **Z in the model (2.5D)** — done: Z along the world's Z with the normal fixed at +Z, stored as
   DXF stores it (what each command does with it is in its row and under "Where a point's Z comes
   from"). 3D solids (ACIS: B-rep, booleans, shading) are off the roadmap: a separate kernel the size
   of everything built so far, which neither reuses nor cheapens any of this — a product decision,
   not a debt.
2. **Views and the tilted plane** — done: parallel views from any direction (-VPOINT, `-VIEW`'s
   presets, PLAN, 3DORBIT) that draw elevation and thickness, a normal per entity with its points
   in their OCS (DXF 210), and the tilted UCS the commands work in (X, Y, ZAxis, three points, View,
   OBject, UCSORTHO). It lifted the 2.5D deviations of CIRCLE 3P, ARC and FILLET / CHAMFER of
   sloping lines. Left, each a gap of its own: perspective and the rest of 3D navigation, saved
   views, UCS Face (no solids) and Apply, grips other than move on a tilted object, the Normal rows
   on types other than circle and arc, Intersection between objects in different planes, PROJMODE's
   projection of objects at an angle to the UCS, and JOIN's 3D polyline (it waits for 3DPOLY).
3. **3D usability** — done: the `+Z` / `-Z` guide of Polar, Ortho and OTRACK with a typed length
   along it, the ViewCube (parts, drag, roll, triangles, Home, compass, its two menus, NAVVCUBE)
   the viewport controls' view menu and the navigation bar (Pan, Zoom, Orbit). Left, each a gap of its own: perspective,
   the ViewCube Settings dialog and its variables, SteeringWheels and
   ShowMotion, named views, the dynamic UCS (UCSDETECT), UCSFOLLOW, and the tracking label of OTRACK.

Left out of the 2.5D model, each a gap of its own: SPLINE 3D (a 3D NURBS kernel) and 3DPOLY, LIST,
the `.X` / `.XY` point filters, OSNAPZ as a variable, ARRAYRECT's Levels, CHPROP, and POINT's
thickness (with POINT, below).

Editing a spline — OFFSET (which is also what the ellipse's OFFSET and FILLET wait for), TRIM /
EXTEND of one an edge reaches (its own knots), BREAK / JOIN, SPLINEDIT — is a command gap, so it queues behind the model gap above.

Deferrable indefinitely at no extra cost: PASTEBLOCK/PASTEORIG/CUTBASE, DIMARC, DIMORDINATE, the
modern `DIM` command, POINT with DIVIDE/MEASURE, XLINE/RAY, GROUP, LENGTHEN, ALIGN, per-object
ltscale, isometric drafting mode.

Blocks family, not on the near-term path: ByBlock resolution, non-uniform scale (the ellipse exists
now; what is left is a per-axis scale vocabulary), inserting external drawing files + INSUNITS,
`-BLOCK` Mode keywords, `-INSERT` Basepoint/Corner/XYZ/Explode/Repeat, BASE, WBLOCK, BEDIT, MINSERT,
XREF, BREPLACE, dynamic blocks, DIVIDE/MEASURE with a block, a block table manager, ATTSYNC,
BATTMAN, ATTEXT / DATAEXTRACTION, multiline attributes.

DXF import/export and plot-to-PDF remain end-of-roadmap and unscheduled.
