# i18n glossary

The CAD vocabulary of MellowCAD's interface in each language, and where each term comes from. The
Spanish column is Autodesk's own Spanish localization of AutoCAD 2026, never a translation of ours:
someone who works in Spanish AutoCAD must find the words they already know. There is no Arabic
AutoCAD, so the Arabic column is worded by the project. It went live without a native speaker's
review, which no one was available for (`docs/autocad-coverage.md`, "Arabic interface").

This file covers the **interface language** — palettes, menus, tooltips, the landing. The **command
language** (command names, aliases, prompts, keywords) is Spanish AutoCAD's own, in
`cad/locales/es.json`; each command's Spanish name and what is still unverified are in
`docs/autocad-coverage.md`. Arabic has no command language of its own: it is the global one.

## Sources

Autodesk's Spanish help uses the same GUIDs as the English one. `C` below is
`https://help.autodesk.com/cloudhelp/2026/ESP/AutoCAD-Core/files/GUID-<id>.htm`; `GS`, `DYK`, `CU`
and `MAC` are the same URL with `AutoCAD-GettingStarted`, `AutoCAD-DidYouKnow`,
`AutoCAD-Customization` or `AutoCAD-MAC-Core` in place of `AutoCAD-Core`. A term marked
**partial** was read in prose or an older release; **no** means not confirmed anywhere yet — settle
it from a screenshot of the Spanish product before relying on it.

For the command line the best source is the product's own string table: Autodesk's public AutoCAD
2027 Spanish language pack (`Autodesk_AutoCAD_2027_Spanish_Language_Pack.exe`, linked from the
forum thread "2027 Product download links") holds `es-ES/acadres.dll`, which 7-Zip extracts without
running anything. Its string ids match an English `acadres.dll`'s, so each prompt, keyword list and
message pairs with its English one. A message assembled at run time from pieces (`%d line%s %sed`)
is composed the same way in Spanish; one the table words twice is marked unverified.

The Arabic column marks how each term was chosen, since no Autodesk source exists: **(C)** the word
Arabic AutoCAD courses and books use (أوتوكاد tutorials name tools this way: تشذيب، تقويس، شطف،
تهشير، الطبقة); **(M)** the Modern Standard Arabic technical or mathematical term (قطع ناقص، مماس،
متساوي القياس، المسقط الأفقي); **(L)** worded from the English for want of any precedent. **†**
marks a choice between competing terms that a native review should settle first — for example التقاط
الكائنات against خطف الكائنات for object snap, or مكعب العرض against keeping ViewCube.

## Never translated

- **Drawing data:** layer, block and style names (`0`, `Standard`, `ISO-25`), linetype names
  (`Continuous`, `Dashed`…) and hatch pattern names (`SOLID`, `ANSI31`). They are the drawing's, as
  in AutoCAD, so `cad/locales/es.json` leaves `interface.linetype` and `interface.hatchPattern` out.
- **Technical values:** a point for decimals, a comma between coordinates, latin digits, in every
  language.
- **Brand and notation:** MellowCAD, AutoCAD, DWG, DXF, the axis names X and Y.

## Register

- **Landing:** tú, short sentences, the English tone («Escribe L. Pulsa Intro. Dibuja.»).
- **Editor:** Autodesk's register — labels as infinitives and nouns («Guardar dibujo», «Definir
  actual»), sentences in usted («Escriba un comando»).
- **Arabic:** Modern Standard Arabic, neutral across the region. The landing speaks to the reader
  in the imperative («اكتب L. اضغط Enter. ارسم.»); the editor labels with verbal nouns («حفظ
  الرسم», «تعيين طبقةً حالية») and asks in the imperative («اكتب أمرًا»). «حاسوب», not كمبيوتر;
  «أوتوكاد» in prose, AutoCAD in the trademark notice. Arabic punctuation (، ؛ ؟), «» in prose,
  latin digits. A command name, key, URL or value inside Arabic text is isolated (FSI…PDI).
- **Neutral Spanish:** no vosotros or voseo; «equipo» or «dispositivo», «archivo», «ratón» (as
  Autodesk's help writes it); «» in prose, em dashes attached to the aside.

## Search texts

A page's title, description and lead are written from what people search in that language, never
translated from the English ones. Each claim below is what the research found; redo it before
rewriting the copy.

- **Spanish** (Google's suggestions in Spain, Mexico, Argentina, Colombia and Chile, and the titles
  ranking there, 27/09/2026; no volumes, Trends could not be read): «gratis» goes with every query
  («cad online gratis», «cad 2d online gratis»); «CAD online» is said so, not «en línea», which
  finds file viewers; «sin registro» is how _no sign-up_ is said; «comandos de AutoCAD» is common.
  Never «AutoCAD online gratis», which would read as if this were AutoCAD. Title: «CAD 2D online
  gratis con comandos de AutoCAD — MellowCAD» (56); description: «CAD 2D gratis en tu navegador con
  los comandos, alias y referencias a objetos de AutoCAD. Sin instalación ni registro; tus dibujos
  no salen de tu equipo.» (153). The lead carries the terms the H1 lacks.
- **Arabic** (Google's suggestions in Saudi Arabia, Egypt, the Emirates, Morocco, Iraq and Jordan,
  01/10/2026): «أوتوكاد» (with or without hamza), «رسم هندسي» (technical drawing), «ثنائي
  الأبعاد», «أون لاين» (not «عبر الإنترنت»), «مجاني/مجانا» and «أوامر الأوتوكاد واختصاراتها»
  («اختصارات» is the word for aliases). «كاد» alone finds Cadillac, and «بديل أوتوكاد» is not
  searched and would read as if this were AutoCAD. Title: «رسم هندسي ثنائي الأبعاد أون لاين مجانًا
  بأوامر أوتوكاد — MellowCAD».
