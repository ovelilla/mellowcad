## 命令行 [#commandline]

| 按键 | 功能 | 命令 |
| --- | --- | --- |
| `Enter`, `Space` | 执行已输入的内容。未输入任何内容时，采用提示的默认值或结束命令；没有运行命令时，重复上一个命令。 |  |
| `Esc` | 取消正在运行的命令；如有输入到一半的内容，第一次按 Esc 键先将其清除。 |  |
| `↑`, `↓` | 没有运行命令时，调出之前输入的命令。 |  |
| `Tab` | 补全正在输入的命令名；在指定点的提示下，依次切换光标下的对象捕捉。 |  |
| `Shift+Space` | 显示选择循环标记时，依次切换光标下重叠的对象。 |  |
