Klawisze, na które odpowiada MellowCAD – te, które użytkownik AutoCADa ma już w palcach. Polecenie jest podane tak, jak się je wpisuje; jego aliasy są na stronie poleceń.

## Pomoce rysunkowe [#aids]

| Klawisz | Działanie | Polecenie |
| --- | --- | --- |
| `F1` | Otwiera pomoc bieżącego polecenia w nowej karcie, a gdy żadne nie działa – tę dokumentację. |  |
| `F2` | Historia poleceń |  |
| `F3` | Lokalizacja względem obiektu |  |
| `F4` | Wybieranie cykliczne |  |
| `F7` | Siatka |  |
| `F8`, `Ctrl+L` | Tryb orto |  |
| `F9` | Tryb skoku |  |
| `F10` | Śledzenie biegunowe |  |
| `F11` | Śledzenie lokalizacji |  |

| `Ctrl+S` | Zapisuje bieżący rysunek | `SZAPISZ` |
| `Ctrl+Shift+S` | Zapisuje kopię bieżącego rysunku w pliku o nowej nazwie | `NZAPISZ` |
| `Ctrl+O` | Otwiera istniejący plik rysunku | `OTWÓRZ` |

## Wiersz polecenia [#commandline]

| Klawisz | Działanie | Polecenie |
| --- | --- | --- |
| `Enter`, `Spacja` | Wykonuje to, co wpisano. Gdy nic nie wpisano, przyjmuje wartość domyślną monitu lub kończy polecenie, a gdy żadne polecenie nie działa, powtarza ostatnie. |  |
| `Esc` | Anuluje bieżące polecenie; pierwsze naciśnięcie Esc czyści częściowo wpisany tekst. |  |
| `↑`, `↓` | Gdy żadne polecenie nie działa, przywołuje wcześniej wpisane polecenia. |  |
| `Tab` | Uzupełnia wpisywaną nazwę polecenia; przy monicie o punkt przełącza kolejno tryby lokalizacji pod kursorem. |  |
| `Shift+Spacja` | Przełącza kolejno nakładające się obiekty pod kursorem, gdy wybieranie cykliczne pokazuje swój znaczek. |  |
