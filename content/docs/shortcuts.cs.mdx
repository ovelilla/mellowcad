Klávesy, na které MellowCAD reaguje – ty, které má uživatel AutoCADu už v prstech. Příkaz je uveden tak, jak se zadává; jeho aliasy jsou na stránce příkazů.

## Pomůcky pro kreslení [#aids]

| Klávesa | Co dělá | Příkaz |
| --- | --- | --- |
| `F1` | Otevře nápovědu k běžícímu příkazu na nové kartě, a když žádný neběží, tuto dokumentaci. |  |
| `F2` | Historie příkazů |  |
| `F3` | Uchopení objektů |  |
| `F4` | Přepínání výběrů |  |
| `F7` | Rastr |  |
| `F8`, `Ctrl+L` | Režim Orto |  |
| `F9` | Režim kroku |  |
| `F10` | Polární trasování |  |
| `F11` | Trasování uchopení objektů |  |

## Úpravy a soubory [#editing]

| Klávesa | Co dělá | Příkaz |
| --- | --- | --- |
| `Ctrl+Z` | Vrátí poslední akci | `Z` |
| `Ctrl+Y`, `Ctrl+Shift+Z` | Vícenásobné znovu | `NZNOVA` |
| `Ctrl+C` | Kopírovat | `SKOPIE` |
| `Ctrl+Shift+C` | Kopírovat se základním bodem | `SKOPIEREF` |
| `Ctrl+X` | Vyjmout | `VYJMIS` |
| `Ctrl+V` | Vloží objekty ze schránky do aktuálního výkresu | `SVLOŽ` |
| `Ctrl+A` | Vybere všechny objekty |  |
| `Ctrl+S` | Uloží aktuální výkres | `RULOŽ` |
| `Ctrl+Shift+S` | Uloží kopii aktuálního výkresu pod novým názvem | `ULOŽJAKO` |
| `Ctrl+O` | Otevře stávající výkresový soubor | `OTEVŘI` |

## Okno [#window]

| Klávesa | Co dělá | Příkaz |
| --- | --- | --- |
| `Ctrl+1` | Zobrazí vlastnosti vybraných objektů | `VLASTNOSTI` / `ZAVŘIVL` |

| `Ctrl+9` | Příkazový řádek |  |

## Příkazový řádek [#commandline]

| Klávesa | Co dělá | Příkaz |
| --- | --- | --- |
| `Enter`, `Mezerník` | Provede, co je zadáno. Když není nic zadáno, přijme výchozí hodnotu výzvy nebo ukončí příkaz, a když žádný příkaz neběží, zopakuje poslední. |  |
| `Esc` | Zruší běžící příkaz; první Esc vymaže rozepsaný text. |  |
| `↑`, `↓` | Když žádný příkaz neběží, vyvolá dříve zadané příkazy. |  |
| `Tab` | Doplní rozepsaný název příkazu; u výzvy k zadání bodu postupně přepíná režimy uchopení objektů pod kurzorem. |  |
| `Shift+Mezerník` | Postupně přepíná překrývající se objekty pod kurzorem, když přepínání výběrů ukazuje svůj odznak. |  |
