MellowCAD가 응답하는 키로, AutoCAD 사용자의 손에 이미 익은 것들입니다. 명령은 입력하는 그대로의 이름으로 적었고, 명령별 단축키는 명령어 페이지에 있습니다.

## 제도 보조 도구 [#aids]

| 키 | 기능 | 명령 |
| --- | --- | --- |
| `F1` | 실행 중인 명령의 도움말을 새 탭에서 엽니다. 실행 중인 명령이 없으면 이 문서를 엽니다. |  |
| `F2` | 명령 사용 내역 |  |
| `F3` | 객체 스냅 |  |
| `F4` | 선택 순환 |  |
| `F7` | 그리드 |  |
| `F8`, `Ctrl+L` | 직교 모드 |  |
| `F9` | 스냅 모드 |  |
| `F10` | 극좌표 추적 |  |
| `F11` | 객체 스냅 추적 |  |

## 편집과 파일 [#editing]

| 키 | 기능 | 명령 |
| --- | --- | --- |
| `Ctrl+Z` | 가장 최근의 작업을 취소합니다 | `U` |
| `Ctrl+Y`, `Ctrl+Shift+Z` | 다중 명령 복구 | `MREDO` |
| `Ctrl+C` | 클립 복사 | `COPYCLIP` |
| `Ctrl+Shift+C` | 기준점을 사용하여 복사 | `COPYBASE` |
| `Ctrl+X` | 잘라내기 | `CUTCLIP` |
| `Ctrl+V` | 클립보드의 객체를 현재 도면에 붙여 넣습니다 | `PASTECLIP` |
| `Ctrl+A` | 모든 객체 선택 |  |
| `Ctrl+S` | 현재 도면을 저장합니다 | `QSAVE` |
| `Ctrl+Shift+S` | 현재 도면을 새 파일 이름으로 저장합니다 | `SAVEAS` |
| `Ctrl+O` | 기존의 도면 파일을 엽니다 | `OPEN` |

## 명령행 [#commandline]

| 키 | 기능 | 명령 |
| --- | --- | --- |
| `Enter`, `Space` | 입력한 내용을 실행합니다. 아무것도 입력하지 않았으면 프롬프트의 기본값을 쓰거나 명령을 끝내고, 실행 중인 명령이 없으면 마지막 명령을 반복합니다. |  |
| `Esc` | 실행 중인 명령을 취소합니다. 입력하다 만 내용이 있으면 첫 Esc 키로 그것을 지웁니다. |  |
| `↑`, `↓` | 실행 중인 명령이 없을 때 이전에 입력한 명령을 다시 불러옵니다. |  |
| `Tab` | 입력 중인 명령 이름을 완성합니다. 점 프롬프트에서는 커서 아래의 객체 스냅을 차례로 바꿉니다. |  |
| `Shift+Space` | 선택 순환 배지가 표시되는 동안 커서 아래에 겹친 객체를 차례로 바꿉니다. |  |
