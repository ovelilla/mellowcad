MellowCAD 回應的按鍵，也就是 AutoCAD 使用者手指早已熟悉的按鍵。指令以您輸入的方式表示；其快捷鍵（指令別名）列在指令頁面上。

## 繪圖輔助 [#aids]

| 按鍵 | 功能 | 指令 |
| --- | --- | --- |
| `F1` | 在新分頁中開啟執行中指令的說明；沒有執行中的指令時，開啟本文件。 |  |
| `F2` | 指令歷程 |  |
| `F3` | 物件鎖點 |  |
| `F4` | 選集循環 |  |
| `F7` | 格線 |  |
| `F8`, `Ctrl+L` | 正交模式 |  |
| `F9` | 鎖點模式 |  |
| `F10` | 極座標追蹤 |  |
| `F11` | 物件鎖點追蹤 |  |

## 編輯與檔案 [#editing]

| 按鍵 | 功能 | 指令 |
| --- | --- | --- |
| `Ctrl+Z` | 倒回最近的動作 | `U` |
| `Ctrl+Y`, `Ctrl+Shift+Z` | 多重重做 | `MREDO` |
| `Ctrl+C` | 複本截取 | `COPYCLIP` |
| `Ctrl+Shift+C` | 以基準點複製 | `COPYBASE` |
| `Ctrl+X` | 剪下 | `CUTCLIP` |
| `Ctrl+V` | 將物件從剪貼簿貼到目前圖面中 | `PASTECLIP` |
| `Ctrl+A` | 選取所有物件 |  |
| `Ctrl+S` | 儲存目前的圖面 | `QSAVE` |
| `Ctrl+Shift+S` | 以新檔名儲存目前的圖面 | `SAVEAS` |
| `Ctrl+O` | 開啟既有的圖檔 | `OPEN` |

## 視窗 [#window]

| 按鍵 | 功能 | 指令 |
| --- | --- | --- |
| `Ctrl+1` | 顯示選取物件的性質 | `PROPERTIES` / `PROPERTIESCLOSE` |
| `Ctrl+0` | 清除螢幕上的工具列和選項板 | `CLEANSCREENON` / `CLEANSCREENOFF` |
| `Ctrl+9` | 指令行 |  |

## 指令行 [#commandline]

| 按鍵 | 功能 | 指令 |
| --- | --- | --- |
| `Enter`, `空格鍵` | 執行已輸入的內容。未輸入任何內容時，採用提示的預設值或結束指令；沒有執行中的指令時，重複上一個指令。 |  |
| `Esc` | 取消執行中的指令；第一次按 Esc 會清除輸入到一半的內容。 |  |
| `↑`, `↓` | 沒有執行中的指令時，叫回先前輸入的指令。 |  |
| `Tab` | 自動完成正在輸入的指令名稱；在點的提示下，循環切換游標下的物件鎖點。 |  |
| `Shift+空格鍵` | 選集循環顯示其標記時，循環切換游標下重疊的物件。 |  |
