Die Tasten, auf die MellowCAD antwortet, die jemand, der AutoCAD nutzt, schon im Finger hat. Ein Befehl steht so, wie Sie ihn eingeben; seine Aliasnamen stehen auf der Befehlsseite.

## Zeichenhilfen [#aids]

| Taste | Was sie bewirkt | Befehl |
| --- | --- | --- |
| `F1` | Öffnet die Hilfe des laufenden Befehls in einem neuen Tab, ohne Befehl diese Dokumentation. |  |
| `F2` | Command history |  |
| `F3` | Object snap |  |
| `F4` | Selection cycling |  |
| `F7` | Grid |  |
| `F8`, `Strg+L` | Ortho mode |  |
| `F9` | Snap mode |  |
| `F10` | Polar tracking |  |
| `F11` | Object snap tracking |  |

## Bearbeiten und Dateien [#editing]

| Taste | Was sie bewirkt | Befehl |
| --- | --- | --- |
| `Strg+Z` | Macht den letzten Vorgang rückgängig | `Z` |
| `Strg+Y`, `Strg+Umschalt+Z` | Mehrfach wiederherstellen | `MZLÖSCH` |
| `Strg+C` | Kopieren | `COPYCLIP` |
| `Strg+Umschalt+C` | Kopieren mit Basispunkt | `KOPIEBASISP` |
| `Strg+X` | Ausschneiden | `AUSSCHNEIDEN` |
| `Strg+V` | Fügt den Inhalt der Zwischenablage in die Zeichnung ein | `CLIPEINFÜG` |
| `Strg+A` | Wählt jedes Objekt |  |
| `Strg+S` | Speichert die aktuelle Zeichnung | `KSICH` |
| `Strg+Umschalt+S` | Speichert eine Kopie der aktuellen Zeichnung unter einem neuen Dateinamen | `SICHALS` |
| `Strg+O` | Öffnet eine bestehende Zeichnungsdatei | `ÖFFNEN` |

## Fenster [#window]

| Taste | Was sie bewirkt | Befehl |

| `Strg+1` | Zeigt die Eigenschaften der gewählten Objekte an | `EIGENSCHAFTEN` / `EIGSCHLIESS` |

## Befehlszeile [#commandline]

| Taste | Was sie bewirkt | Befehl |
| --- | --- | --- |
| `Eingabetaste`, `Leertaste` | Führt das Eingegebene aus. Ohne Eingabe übernimmt sie die Vorgabe der Eingabeaufforderung oder beendet den Befehl, und ohne laufenden Befehl wiederholt sie den letzten. |  |
| `Esc` | Bricht den laufenden Befehl ab; ein erstes Esc löscht das halb Eingegebene. |  |
| `↑`, `↓` | Ohne laufenden Befehl holt sie die zuvor eingegebenen Befehle zurück. |  |
| `Tab` | Vervollständigt den eingegebenen Befehlsnamen; bei einer Punktaufforderung schaltet sie durch die Objektfangmodi unter dem Cursor. |  |
| `Umschalt+Leertaste` | Schaltet durch die überlappenden Objekte unter dem Cursor, solange die wechselnde Auswahl ihr Symbol zeigt. |  |
