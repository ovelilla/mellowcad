MellowCAD が応答するキーです。AutoCAD ユーザの指がすでに覚えているものです。コマンドは入力するとおりの名前で示します。短縮コマンドはコマンドのページにあります。

## 作図補助 [#aids]

| キー | 機能 | コマンド |
| --- | --- | --- |
| `F1` | 実行中のコマンドのヘルプを新しいタブで開きます。コマンドを実行していないときは、このドキュメントを開きます。 |  |
| `F2` | コマンド ヒストリ |  |
| `F3` | オブジェクト スナップ |  |
| `F4` | 選択の循環 |  |
| `F6` | ダイナミック UCS |  |
| `F7` | グリッド |  |
| `F8`, `Ctrl+L` | 直交モード |  |
| `F9` | スナップ モード |  |
| `F10` | 極トラッキング |  |
| `F11` | オブジェクト スナップ トラッキング |  |

## 編集とファイル [#editing]

| キー | 機能 | コマンド |
| --- | --- | --- |
| `Ctrl+Z` | 最後の操作を元に戻す | `U` |
| `Ctrl+Y`, `Ctrl+Shift+Z` | 複数回やり直し | `MREDO` |
| `Ctrl+C` | コピー クリップ | `COPYCLIP` |
| `Ctrl+Shift+C` | 基点コピー | `COPYBASE` |
| `Ctrl+X` | 切り取り | `CUTCLIP` |
| `Ctrl+V` | クリップボードのオブジェクトを現在の図面に貼り付け | `PASTECLIP` |
| `Ctrl+A` | すべてのオブジェクトを選択 |  |
| `Ctrl+S` | 現在の図面を保存 | `QSAVE` |
| `Ctrl+Shift+S` | 現在の図面のコピーを新しいファイル名で保存 | `SAVEAS` |
| `Ctrl+O` | 既存の図面ファイルを開く | `OPEN` |

## ウィンドウ [#window]

| キー | 機能 | コマンド |
| --- | --- | --- |
| `Ctrl+1` | 選択したオブジェクトのプロパティを表示 | `PROPERTIES` / `PROPERTIESCLOSE` |
| `Ctrl+0` | ツールバーとパレットを画面から消去 | `CLEANSCREENON` / `CLEANSCREENOFF` |
| `Ctrl+9` | コマンド ライン |  |

## コマンド ライン [#commandline]

| キー | 機能 | コマンド |
| --- | --- | --- |
| `Enter`, `Space` | 入力した内容を実行します。何も入力していないときは、プロンプトの既定値を使うか、コマンドを終了します。コマンドを実行していないときは、直前のコマンドを繰り返します。 |  |
| `Esc` | 実行中のコマンドをキャンセルします。入力途中の文字があるときは、最初の[Esc]でそれを消去します。 |  |
| `↑`, `↓` | コマンドを実行していないとき、以前に入力したコマンドを呼び出します。 |  |
| `Tab` | 入力中のコマンド名を補完します。点を指定するプロンプトでは、カーソル位置のオブジェクト スナップを順に切り替えます。 |  |
| `Shift+Space` | 選択の循環のバッジが表示されている間、カーソル位置で重なっているオブジェクトを順に切り替えます。 |  |
