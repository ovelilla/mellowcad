Клавиши, на которые отвечает MellowCAD, — те, что пальцы пользователя AutoCAD уже помнят. Команда названа так, как вы ее вводите; ее псевдонимы — на странице команд.

## Средства черчения [#aids]

| Клавиша | Действие | Команда |
| --- | --- | --- |
| `F1` | Открывает справку по текущей команде в новой вкладке, а без команды — эту документацию. |  |
| `F2` | Журнал команд |  |
| `F3` | Объектная привязка |  |
| `F4` | Циклический выбор |  |
| `F7` | Сетка |  |
| `F8`, `Ctrl+L` | Режим «Орто» |  |
| `F9` | Шаговая привязка |  |
| `F10` | Полярное отслеживание |  |
| `F11` | Объектное отслеживание |  |

| Клавиша | Действие | Команда |
| --- | --- | --- |
| `Ctrl+Z` | Отмена предыдущей операции | `О` |

| `Ctrl+A` | Выбирает все объекты |  |
| `Ctrl+S` | Сохранение текущего чертежа | `БСОХРАНИТЬ` |
| `Ctrl+Shift+S` | Сохранение текущего чертежа под другим именем | `СОХРАНИТЬКАК` |
| `Ctrl+O` | Открытие существующего файла чертежа | `ОТКРЫТЬ` |

## Командная строка [#commandline]

| Клавиша | Действие | Команда |
| --- | --- | --- |
| `Enter`, `Пробел` | Выполняет введенное. Без ввода принимает значение по умолчанию в запросе или завершает команду, а когда ни одна команда не выполняется, повторяет последнюю. |  |
| `Esc` | Отменяет текущую команду; первое нажатие Esc стирает частично введенное. |  |
| `↑`, `↓` | Когда ни одна команда не выполняется, возвращает ранее введенные команды. |  |
| `Tab` | Дополняет вводимое имя команды; в запросе точки перебирает режимы объектной привязки под курсором. |  |
| `Shift+Пробел` | Перебирает перекрывающиеся объекты под курсором, пока циклический выбор показывает свой значок. |  |
