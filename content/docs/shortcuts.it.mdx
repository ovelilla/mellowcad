I tasti a cui MellowCAD risponde, quelli che chi usa AutoCAD ha già nelle dita. Un comando è nominato come lo digiteresti; i suoi alias sono nella pagina dei comandi.

## Ausili di disegno [#aids]

| Tasto | Cosa fa | Comando |
| --- | --- | --- |
| `F1` | Apre la guida del comando in corso in una nuova scheda, o queste guide se non ce n'è nessuno. |  |
| `F2` | Cronologia dei comandi |  |
| `F3` | Snap ad oggetto |  |
| `F4` | Selezione ciclica |  |
| `F7` | Griglia |  |
| `F8`, `Ctrl+L` | Modalità orto |  |
| `F9` | Modalità snap |  |
| `F10` | Puntamento polare |  |
| `F11` | Puntamento snap ad oggetto |  |

## Modifica e file [#editing]

| Tasto | Cosa fa | Comando |
| --- | --- | --- |
| `Ctrl+Z` | Annulla l'ultima operazione | `A` |
| `Ctrl+Y`, `Ctrl+Maiusc+Z` | Ripeti multiplo | `MRIPETI` |
| `Ctrl+C` | Copia | `COPIACLIP` |
| `Ctrl+Maiusc+C` | Copia con punto base | `COPIAPUNTOB` |
| `Ctrl+X` | Taglia | `TAGLIACLIP` |
| `Ctrl+V` | Incolla il contenuto degli Appunti nel disegno | `INCOLLACLIP` |
| `Ctrl+A` | Seleziona tutti gli oggetti |  |
| `Ctrl+S` | Salva il disegno in un file | `SALVAVEL` |
| `Ctrl+Maiusc+S` | Salva il disegno in un file con un nuovo nome | `SALVACOME` |
| `Ctrl+O` | Apre un file di disegno | `APRI` |

## Finestra [#window]

| Tasto | Cosa fa | Comando |
| --- | --- | --- |
| `Ctrl+1` | Visualizza le proprietà degli oggetti selezionati | `PROPRIETA` / `CHIUDIPROP` |
| `Ctrl+0` | Rimuove dallo schermo le barre degli strumenti e le tavolozze | `ATTSCHINT` / `DISATTSCHINT` |
| `Ctrl+9` | Riga di comando |  |

## Riga di comando [#commandline]

| Tasto | Cosa fa | Comando |
| --- | --- | --- |
| `Invio`, `Spazio` | Esegue ciò che è digitato. Senza nulla di digitato prende il valore predefinito della richiesta o termina il comando, e senza comandi in corso ripete l'ultimo. |  |
| `Esc` | Annulla il comando in corso; un primo Esc cancella ciò che è digitato a metà. |  |
| `↑`, `↓` | Senza comandi in corso, richiama i comandi digitati prima. |  |
| `Tab` | Completa il nome del comando che stai digitando; a una richiesta di punto, passa da uno snap ad oggetto all'altro sotto il cursore. |  |
| `Maiusc+Spazio` | Passa da un oggetto sovrapposto all'altro sotto il cursore mentre il ciclo di selezione mostra il suo badge. |  |
