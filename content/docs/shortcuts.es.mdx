Las teclas que responde MellowCAD, las que un usuario de AutoCAD ya tiene en los dedos. Cada comando se nombra como lo escribirías; sus alias están en la página de comandos.

## Ayudas al dibujo [#aids]

| Tecla | Qué hace | Comando |
| --- | --- | --- |
| `F1` | Abre en una pestaña nueva la ayuda del comando en curso, o esta documentación si no hay ninguno. |  |
| `F2` | Historial de comandos |  |
| `F3` | Referencia a objetos |  |
| `F4` | Ciclo de selección |  |
| `F7` | Rejilla |  |
| `F8`, `Ctrl+L` | Modo Orto |  |
| `F9` | Modo Forzcursor |  |
| `F10` | Rastreo polar |  |
| `F11` | Rastreo de referencia a objetos |  |

## Edición y archivos [#editing]

| Tecla | Qué hace | Comando |
| --- | --- | --- |
| `Ctrl+Z` | Deshacer la última acción | `H` |

| `Ctrl+C` | Copiar | `COPIAPP` |
| `Ctrl+Mayús+C` | Copiar con punto base | `COPIARBASE` |
| `Ctrl+X` | Cortar | `CORTAPP` |
| `Ctrl+V` | Pegar el portapapeles en el dibujo | `PEGAPP` |
| `Ctrl+A` | Seleccionar todos los objetos |  |
| `Ctrl+S` | Guardar el dibujo en un archivo | `GUARDARR` |
| `Ctrl+Mayús+S` | Guardar el dibujo en un archivo con otro nombre | `GUARDARCOMO` |
| `Ctrl+O` | Abrir un archivo de dibujo | `ABRE` |

## Línea de comandos [#commandline]

| Tecla | Qué hace | Comando |
| --- | --- | --- |
| `Intro`, `Espacio` | Ejecuta lo escrito. Sin nada escrito toma el valor por defecto de la solicitud o termina el comando, y sin un comando en curso repite el último. |  |
| `Esc` | Cancela el comando en curso; un primer Esc borra lo que está a medio escribir. |  |
| `↑`, `↓` | Sin un comando en curso, recupera los comandos escritos antes. |  |
| `Tab` | Completa el nombre del comando que se escribe; al pedir un punto, recorre las referencias a objetos bajo el cursor. |  |
| `Mayús+Espacio` | Recorre los objetos superpuestos bajo el cursor mientras el ciclo de selección muestra su indicador. |  |
