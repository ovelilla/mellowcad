المفاتيح التي يستجيب لها MellowCAD، وهي التي اعتادتها أصابع مستخدم أوتوكاد. يُسمّى كل أمر كما تكتبه، واختصاراته في صفحة الأوامر.

## مساعدات الرسم [#aids]

| المفتاح | ما يفعله | الأمر |
| --- | --- | --- |
| `F1` | يفتح في تبويب جديد مساعدة الأمر قيد التشغيل، أو هذا التوثيق إن لم يكن هناك أمر. |  |
| `F2` | سجل الأوامر |  |
| `F3` | التقاط الكائنات |  |
| `F4` | تدوير التحديد |  |
| `F7` | الشبكة |  |
| `F8`, `Ctrl+L` | الوضع المتعامد |  |
| `F9` | وضع الالتقاط |  |
| `F10` | التتبع القطبي |  |
| `F11` | تتبع التقاط الكائنات |  |

## التحرير والملفات [#editing]

| المفتاح | ما يفعله | الأمر |
| --- | --- | --- |
| `Ctrl+Z` | التراجع عن آخر إجراء | `U` |
| `Ctrl+Y`, `Ctrl+Shift+Z` | إعادة متعددة | `MREDO` |
| `Ctrl+C` | نسخ | `COPYCLIP` |
| `Ctrl+Shift+C` | نسخ بنقطة أساس | `COPYBASE` |
| `Ctrl+X` | قص | `CUTCLIP` |
| `Ctrl+V` | لصق محتوى الحافظة في الرسم | `PASTECLIP` |
| `Ctrl+A` | تحديد كل الكائنات |  |
| `Ctrl+S` | حفظ الرسم في ملف | `QSAVE` |
| `Ctrl+Shift+S` | حفظ الرسم في ملف باسم جديد | `SAVEAS` |
| `Ctrl+O` | فتح ملف رسم | `OPEN` |

## النافذة [#window]

| المفتاح | ما يفعله | الأمر |
| --- | --- | --- |
| `Ctrl+1` | عرض خصائص العناصر المحددة | `PROPERTIES` / `PROPERTIESCLOSE` |
| `Ctrl+0` | إخلاء الشاشة من أشرطة الأدوات واللوحات | `CLEANSCREENON` / `CLEANSCREENOFF` |
| `Ctrl+9` | سطر الأوامر |  |

## سطر الأوامر [#commandline]

| المفتاح | ما يفعله | الأمر |
| --- | --- | --- |
| `Enter`, `Space` | ينفّذ ما كُتب. وإن لم يُكتب شيء يأخذ القيمة الافتراضية للمطالبة أو ينهي الأمر، وإن لم يكن هناك أمر قيد التشغيل يكرّر الأمر الأخير. |  |
| `Esc` | يلغي الأمر قيد التشغيل، وأول ضغطة على ⁨Esc⁩ تمحو ما كُتب نصفه. |  |
| `↑`, `↓` | إن لم يكن هناك أمر قيد التشغيل، يستعيد الأوامر المكتوبة من قبل. |  |
| `Tab` | يكمل اسم الأمر الذي يُكتب، وعند طلب نقطة يتنقّل بين نقاط التقاط الكائنات تحت المؤشر. |  |
| `Shift+Space` | يتنقّل بين الكائنات المتراكبة تحت المؤشر ما دام تدوير التحديد يُظهر شارته. |  |
