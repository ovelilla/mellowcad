Les touches auxquelles MellowCAD répond, celles qu'un utilisateur d'AutoCAD a déjà dans les doigts. Une commande est nommée comme vous la taperiez ; ses alias sont sur la page des commandes.

## Aides au dessin [#aids]

| Touche | Ce qu'elle fait | Commande |
| --- | --- | --- |
| `F1` | Ouvre l'aide de la commande en cours dans un nouvel onglet, ou cette documentation s'il n'y en a pas. |  |
| `F2` | Historique des commandes |  |
| `F3` | Accrochage aux objets |  |
| `F4` | Cycle de sélection |  |
| `F7` | Grille |  |
| `F8`, `Ctrl+L` | Mode ortho |  |
| `F9` | Mode Résolution |  |
| `F10` | Repérage polaire |  |
| `F11` | Repérage d'accrochage aux objets |  |

## Modification et fichiers [#editing]

| Touche | Ce qu'elle fait | Commande |
| --- | --- | --- |
| `Ctrl+Z` | Annule la dernière action | `U` |
| `Ctrl+Y`, `Ctrl+Maj+Z` | Rétablir multiple | `MRETABLIR` |
| `Ctrl+C` | Copier | `COPIERPRESS` |
| `Ctrl+Maj+C` | Copier avec point de base | `COPIERBASE` |
| `Ctrl+X` | Couper | `COUPERPRESS` |
| `Ctrl+V` | Colle le contenu du Presse-papiers dans le dessin | `COLLERPRESS` |
| `Ctrl+A` | Sélectionne tous les objets |  |
| `Ctrl+S` | Enregistre le dessin dans un fichier | `SAUVERAP` |
| `Ctrl+Maj+S` | Enregistre le dessin dans un fichier sous un nouveau nom | `SAUVENOM` |
| `Ctrl+O` | Ouvre un fichier de dessin | `OUVRIR` |

## Fenêtre [#window]

| Touche | Ce qu'elle fait | Commande |
| --- | --- | --- |
| `Ctrl+1` | Affiche les propriétés des objets sélectionnés | `PROPRIETES` / `FERMERPROPRIETES` |
| `Ctrl+0` | Supprime de l'écran les barres d'outils et les palettes | `NETECRANACTIF` / `NETECRANINACTIF` |
| `Ctrl+9` | Ligne de commande |  |

## Ligne de commande [#commandline]

| Touche | Ce qu'elle fait | Commande |
| --- | --- | --- |
| `Entrée`, `Espace` | Exécute ce qui est tapé. Sans rien de tapé, prend la valeur par défaut de l'invite ou termine la commande, et sans commande en cours, répète la dernière. |  |
| `Echap` | Annule la commande en cours ; un premier Echap efface ce qui est à moitié tapé. |  |
| `↑`, `↓` | Sans commande en cours, rappelle les commandes tapées auparavant. |  |
| `Tab` | Complète le nom de commande en cours de saisie ; à une invite de point, passe d'un accrochage aux objets à l'autre sous le curseur. |  |
| `Maj+Espace` | Passe d'un objet superposé à l'autre sous le curseur quand le cycle de sélection affiche son badge. |  |
