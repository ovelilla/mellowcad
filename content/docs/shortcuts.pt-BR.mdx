As teclas a que o MellowCAD responde, as que um usuário do AutoCAD já tem nos dedos. Cada comando é nomeado como você o digitaria; seus aliases estão na página de comandos.

## Auxílios de desenho [#aids]

| Tecla | O que faz | Comando |
| --- | --- | --- |
| `F1` | Abre em uma nova aba a ajuda do comando em execução, ou esta documentação se não houver nenhum. |  |
| `F2` | Histórico de comandos |  |
| `F3` | Snap ao objeto |  |
| `F4` | Ciclo de seleção |  |
| `F7` | Grade |  |
| `F8`, `Ctrl+L` | Modo Orto |  |
| `F9` | Modo snap |  |
| `F10` | Rastreamento polar |  |
| `F11` | Rastreamento de snap ao objeto |  |

## Linha de comando [#commandline]

| Tecla | O que faz | Comando |
| --- | --- | --- |
| `Enter`, `Barra de espaço` | Executa o que foi digitado. Sem nada digitado, aceita o valor padrão do prompt ou termina o comando, e sem nenhum comando em execução repete o último. |  |
| `Esc` | Cancela o comando em execução; um primeiro Esc apaga o que estiver digitado pela metade. |  |
| `↑`, `↓` | Sem nenhum comando em execução, traz de volta os comandos digitados antes. |  |
| `Tab` | Completa o nome do comando sendo digitado; quando um ponto é pedido, percorre os snaps ao objeto sob o cursor. |  |
| `Shift+Barra de espaço` | Percorre os objetos sobrepostos sob o cursor enquanto o ciclo de seleção mostra seu indicador. |  |
