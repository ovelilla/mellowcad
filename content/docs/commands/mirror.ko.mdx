MIRROR(대칭) 명령은 선택한 객체를 선에 대해 대칭합니다. 객체를 선택하고 대칭선의 첫 번째 점과 두 번째 점을 지정한 다음, 원본 객체를 지울지 답합니다. 대칭한 결과는 복사본이며, 기본값인 아니오로 답하면 원본이 남습니다. 대칭인 부품을 절반씩 그리는 방법이 이것입니다. 두 점은 UCS의 평면에서 받으므로, 직교 모드를 켜고 그린 대칭선은 수평이나 수직으로 똑바로 대칭합니다. AutoCAD에서 MIRRTEXT가 기본값인 0일 때처럼, 대칭된 문자도 왼쪽에서 오른쪽으로 읽히고 해치는 패턴의 각도를 유지합니다. 실행은 한 단계이므로 명령 취소로 되돌립니다.

- **명령:** `MIRROR`
- **단축키:** `MI`
- **패널:** [수정](/docs/commands#modify)
- **해 보기:** [편집기를 열고](/ko/draw) `MI` 입력 후 Enter 키를 누릅니다.

## 옵션 [#options]

### `Yes` (`Y`) [#yes]

원본 객체를 지우고 대칭한 결과만 남깁니다. 제자리에서 뒤집는 것과 같습니다.

### `No` (`N`) [#no]

기본값입니다. 원본 객체를 대칭한 결과 옆에 남깁니다.

## 아직 지원하지 않는 것 [#missing]

MIRRTEXT와 MIRRHATCH는 0으로 고정입니다. 문자가 거꾸로 읽히도록 대칭되는 일은 없고, 해치 패턴도 대칭되지 않습니다. 대칭한 블록 참조 안의 문자는 따로 놓인 문자처럼 다시 바로 읽히도록 돌아가지만, AutoCAD는 블록과 함께 대칭합니다. 대칭한 타원은 법선을 유지하므로, 같은 곡선이라도 시작 각도와 끝 각도가 AutoCAD와 다르게 읽힙니다. 대칭 결과가 커서를 따라가는 동안에는 각 객체의 색상만 보이고 선종류나 선가중치는 보이지 않습니다.

## 자주 묻는 질문 [#questions]

### AutoCAD 대칭 단축키는?

`MI`를 입력하고 Enter 키나 Space 키를 누릅니다. 전체 명령 이름을 입력해도 되고, AutoCAD의 어느 언어 버전에서나 `_MIRROR`를 쓸 수 있습니다.

### 문자가 뒤집히지 않게 대칭하려면?

따로 할 일은 없습니다. AutoCAD에서 MIRRTEXT가 0일 때처럼 대칭한 문자는 정상적으로 읽히며, 문자 상자가 대칭된 위치에 놓입니다.

### 대칭하고 원본을 지우려면?

MIRROR가 원본 객체를 지울지 물을 때 `Yes`로 답합니다.

### 수평이나 수직으로 대칭하려면?

직교 모드를 켜고(F8) 대칭할 축을 따라 대칭선의 두 점을 지정합니다. 수직선은 좌우를, 수평선은 위아래를 뒤집습니다.
