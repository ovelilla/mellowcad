PROPERTIES(특성) 명령은 특성 팔레트를 엽니다. AutoCAD와 마찬가지로 대화상자가 아니라 팔레트이므로, 객체를 선택하고 그리는 동안에도 도면 옆에 열려 있습니다. 여기서는 팔레트 패널의 탭 하나로 표시되며, `PROPERTIESCLOSE`로 닫을 때까지 열려 있습니다. Ctrl+1을 누르면 표시되고 숨겨지며, 아포스트로피를 붙여 `'PROPERTIES`로 입력하면 실행 중인 명령 안에서 열립니다. 넓은 창에서는 처음부터 열려 있습니다.

객체를 선택하면 그 특성이 표시되며, 행에 새 값을 입력하거나 선택해 특성을 변경합니다. 맨 처음은 AutoCAD와 같은 순서의 일반으로, 색상, 도면층, 선종류, 선가중치, 두께가 있으며 선택한 객체끼리 값이 다르면 `*다양함*`으로 표시됩니다. 그 아래에는 유형마다 고유한 행이 있습니다. 선은 시작점과 끝점, 길이, 각도, 원은 중심, 반지름, 지름, 둘레, 면적이며, 호, 타원, 폴리선의 정점과 폭, 스플라인의 점, 문자, 블록 참조의 행도 있습니다. 좌표는 현재 UCS 기준이며, 선의 길이처럼 표시만 하는 행은 회색으로 표시됩니다. 맨 위의 드롭다운에는 모두와 각 유형이 개수와 함께 나열됩니다. 하나를 고르면 그 유형만 보고 편집합니다. 아무것도 선택하지 않았을 때는 일반에 현재 도면층, 색상, 선종류, 선가중치가 표시되며, 여기서 새 객체에 쓸 값을 설정합니다. 편집 하나하나가 `U`로 되돌릴 수 있는 한 단계입니다.

- **명령:** `PROPERTIES`
- **단축키:** `PR`, `CH`, `MO`
- **패널:** [구성](/docs/commands#organize)
- **해 보기:** [편집기를 열고](/ko/draw) `PR` 입력 후 Enter 키를 누릅니다.

## 자주 묻는 질문 [#questions]

### AutoCAD 특성 팔레트의 단축키는 무엇입니까?

Ctrl+1이며, 한 번 더 누르면 팔레트가 숨겨집니다. 입력하려면 `PR`, `CH`, `MO` 중 하나를 입력하고 Enter 키나 Space 키를 누릅니다. 전체 명령 이름을 입력해도 되고, AutoCAD의 모든 언어 버전에서 `_PROPERTIES`도 됩니다.

### 특성 팔레트가 사라졌을 때 다시 표시하려면 어떻게 합니까?

Ctrl+1을 누르거나 `PR`을 입력합니다. 팔레트가 도면 옆 팔레트 패널의 탭으로 다시 표시됩니다. 팔레트가 표시된 상태에서 Ctrl+1을 누르면 숨겨지므로, 대개 그렇게 사라진 것입니다.

### 여러 객체의 특성을 한 번에 변경하려면 어떻게 합니까?

모두 선택한 다음 행을 변경합니다. 선택한 모든 객체가 새 값을 갖습니다. 값이 서로 다른 행은 값을 설정할 때까지 `*다양함*`으로 표시됩니다. 그중 원만 변경하려면 맨 위의 드롭다운에서 그 유형을 고릅니다.

### PROPERTIES와 MATCHPROP의 차이는 무엇입니까?

PROPERTIES는 선택한 객체의 값을 표시하고 설정합니다. [`MATCHPROP`](/docs/commands/matchprop)은 값을 입력하지 않고 한 객체의 값을 다른 객체로 복사합니다.
