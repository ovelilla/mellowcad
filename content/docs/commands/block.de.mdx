BLOCK speichert eine Gruppe von Objekten unter einem Namen in der Zeichnung, sodass [`EINFÜGE`](/docs/commands/insert) sie beliebig oft wieder einfügen kann, jede Kopie eine Referenz auf diese eine Definition. Er fragt nach einem Namen, dann nach dem Einfügebasispunkt, dem Punkt, an dem jede Blockreferenz platziert wird, dann nach den Objekten. Die Eingabetaste beendet die Auswahl und definiert den Block, und die gewählten Objekte werden an ihrer Stelle zu einer Blockreferenz auf ihn. Der ganze Befehl ist ein Rückgängig-Schritt.

AutoCADs BLOCK öffnet den Dialog „Blockdefinition“, den MellowCAD nicht hat: Hier stellt BLOCK in der Befehlszeile dieselben Fragen wie `-BLOCK`, wie die Konsole von AutoCAD. Ein Name darf Leerzeichen und bis zu 255 Zeichen enthalten, aber keines von `< > / \ " : ; ? * | , =` und keinen Gravis: Die Eingabetaste allein oder ein solcher Name meldet `Ungültiger Block Name.` und fragt erneut. Hat die Zeichnung den Namen schon, in beliebiger Schreibweise, fragt BLOCK, ob der Block neu definiert werden soll: `Ja` oder `Nein` (die Vorgabe, die den Befehl beendet).

- **Befehl:** `BLOCK`
- **Aliasnamen:** `BL`, `ACADBLOCKDIALOG`, `BMAKE`, `BMOD`
- **Gruppe:** [Organisieren](/docs/commands#organize)
- **Ausprobieren:** [Öffnen Sie den Editor](/de/draw), geben Sie `BL` ein und drücken Sie die Eingabetaste.

## Optionen [#options]

### `?` [#list]

Listet die Blöcke der Zeichnung auf: Er fragt, welche aufgelistet werden sollen, Vorgabe `*` für alle, oder ein Name mit Platzhaltern. Er schreibt die passenden Namen und eine Anzahl je Art und endet dann. Anonyme Blöcke, etwa die einer Reihe, werden gezählt, nie benannt.

## Was er noch nicht kann [#missing]

Der Dialog „Blockdefinition“ von AutoCAD: BLOCK fragt in der Befehlszeile. Beim Basispunkt die Optionen Annotativ und Modus (Beibehalten, Löschen): Die Objekte werden immer in eine Blockreferenz umgewandelt. ATTREQ 0, das das Dialogfeld für die Attributwerte überspringt, sowie ATTSYNC, ATTREDEF, BATTMAN und BATTORDER: Ein neu definierter Block lässt die Attribute seiner Referenzen unverändert, wie in AutoCAD. VonBlock: Ein Objekt in einem Block kann nicht die Farbe, den Linientyp oder die Linienstärke der Blockreferenz annehmen, wie es ein auf VonBlock gesetztes Objekt in AutoCAD tut. In einem gedrehten BKS verschiebt AutoCAD 2027 die Objekte, die es umwandelt; hier bleiben sie absichtlich, wo sie waren.

## Fragen [#questions]

### Wie lautet das Alias von BLOCK in AutoCAD?

`BL`, dann die Eingabetaste oder die Leertaste. `B` ist in der deutschen Version BOGEN. In AutoCAD öffnet BLOCK den Dialog „Blockdefinition“; hier fragt er in der Befehlszeile, wie `-BLOCK` (`-BLOCK`) tut. `_BLOCK` funktioniert in jeder Sprache von AutoCAD.

### Wie erstellt man in AutoCAD einen Block?

Geben Sie `BL` ein, einen Namen, wählen Sie dann den Basispunkt, eine Ecke oder die Mitte der Kante, an der der Block sitzen wird, und wählen Sie die Objekte. Die Eingabetaste definiert den Block und macht die Objekte zu einer Blockreferenz auf ihn. Eine vor dem Befehl getroffene Auswahl wird ebenfalls übernommen, nach dem Basispunkt.

### Wie definiert man einen Block neu?

Starten Sie BLOCK mit dem Namen des Blocks und antworten Sie `Ja`, geben Sie dann einen Basispunkt an und wählen Sie die neuen Objekte: Jede Blockreferenz auf den Block zeigt die neue Definition. Die Objekte dürfen keine Blockreferenz auf den Block selbst enthalten; eine solche Auswahl wird abgelehnt, und der Befehl endet.

### Wie erstellt man einen Block mit Attributen?

Definieren Sie zuerst die Attribute mit [`ATTDEF`](/docs/commands/attdef), wählen Sie sie dann zusammen mit den anderen Objekten: Sie kommen in der Reihenfolge in den Block, in der Sie sie wählen. Die Blockreferenz, die sie ersetzt, öffnet ein Dialogfeld mit einem Eingabefeld für jedes Attribut, beschriftet mit dessen Eingabeaufforderung und gefüllt mit dessen Vorgabewert: Die Eingabetaste übernimmt die Werte, Esc behält die Vorgaben.

### Wie löst man einen Block auf?

[`URSPRUNG`](/docs/commands/explode) macht eine Blockreferenz wieder zu den Objekten, die sie zeigt, eine Verschachtelungsebene nach der anderen, jedes auf seinem eigenen Layer und in seiner eigenen Farbe. Attribute kommen als ihre Definitionen zurück; die Werte entfallen.
