UCS[UCS 管理]コマンドは、ユーザ座標系(UCS)を設定します。空間内の任意の位置に原点と X 軸、Y 軸を置くため、XY 平面を傾けることもできます。入力した座標は UCS で読み取られ、作図したものは UCS の XY 平面上に置かれます。原点を直方体の上面に移動すると、中心 `30,20` の円は上面に置かれます。最初に現在の UCS の名前(`*WORLD*`、`*NO NAME*`、または登録した名前)を表示し、新しい原点かオプションを尋ねます。そこで[Enter]を押すとワールドに戻ります。点を指定すると、その Z 座標を含めて原点になり、Z 座標のない点は現在の高度に置かれます。次に、正の X 軸上の点と XY 平面上の点を、現在の UCS で尋ねます。どちらでも[Enter]を押すと、軸はそのまま保持されます。1 点で UCS を移動し、3 点で任意の向きに回転させます。

その後、コマンドは UCS の XY 平面で働きます。[`LINE`](/docs/commands/line) と [`CIRCLE`](/docs/commands/circle) はその平面上に描き、[`BOX`](/docs/commands/box) と [`EXTRUDE`](/docs/commands/extrude) はその平面から UCS の Z 方向に立ち上がります。UCS を変更しても、各オブジェクトはそれぞれの平面を保ちます。[`PLAN`](/docs/commands/plan) は現在の UCS を真上から見ます。UCS は図面に保存され、1 回の実行が 1 回の操作で元に戻せます。MellowCAD の 3D はソリッドのみで、まだ部分的な対応です。

- **コマンド：** `UCS`
- **パネル：** [問い合わせとビュー](/docs/commands#inquiry)
- **試す：** [エディタを開き](/ja/draw)、`UCS` と入力して\[Enter\]を押します。

## オプション [#options]

### `Face` (`F`) [#face]

AutoCAD 2027 と同様に一覧に表示され、UCS をソリッドの面に位置合わせするためのものです。MellowCAD は面を尋ねますが、まだ面への位置合わせはできず、どこをクリックしても面は見つかりません。

### `NAmed` (`NA`) [#named]

名前の付いた UCS を扱います。`Save` は現在の UCS を登録し、すでに登録されている名前を置き換える前に `Yes` か `No` を尋ねます。`Restore` は登録された UCS を現在の UCS にします。名前は大文字・小文字を問わず入力できます。`Delete` はカンマ区切りやワイルドカードで名前を指定して削除します。`?` はそれらを原点と軸とともに一覧表示します。名前にはスペースを使えますが、`<>/\":;|,=*?` と逆引用符は使えません(`Invalid UCS name.`)。

### `OBject` (`OB`) [#object]

選択したオブジェクトに UCS を位置合わせします。線分、円、円弧、楕円、ポリライン、スプライン、文字、マルチ テキスト、属性定義、ブロック参照が使えます。原点と X 軸はオブジェクトの種類ごとに AutoCAD と同じ位置に置かれ、Z 軸はオブジェクト自身の法線になるため、UCS はオブジェクトの平面上に置かれます。ロックされた画層上のオブジェクトも選択できます。ハッチングでは `This object does not define a coordinate system` と表示され、UCS は元のままコマンドが終了します。

### `Previous` (`P`) [#previous]

直前の UCS に戻ります。セッション中に 10 個前まで戻れ、名前の付いた UCS や正投影 UCS も含まれます。戻るものがなくなると、`No previous coordinate system saved.` と表示されます。

### `View` (`V`) [#view]

原点を保ったまま、XY 平面を視線に直交させ、X 軸を画面の水平方向にします。その後に記入した文字は、3D ビューでも画面に対して平らに読めます。

### `World` (`W`) [#world]

決して動かないワールド座標系に戻ります。最初のプロンプトの既定値なので、そこで[Enter]を押すと選択され、高度も 0 に戻ります。

### `X` [#x]

UCS を X 軸の周りに回転させます。既定は 90° で、角度を入力するか、角度を示す点を指定します。正の角度は右手の法則で回転するため、90 では XY 平面が元の X 軸を軸に立ち上がります。

### `Y` [#y]

`X` が X 軸の周りに回転させるのと同様に、UCS を Y 軸の周りに回転させます。

### `Z` [#z]

`X` が X 軸の周りに回転させるのと同様に、UCS を Z 軸の周りに回転させます。30 では、上から見て X 軸と Y 軸が反時計回りに 30° 回転します。

### `ZAxis` (`ZA`) [#zaxis]

新しい原点([Enter]で現在の原点を保持)を尋ね、次に正の Z 軸上の点を尋ねます。XY 平面はその軸に直交し、X 軸はワールドの XY 平面に対して水平に保たれます。2 点が同じ点の場合は `Points are coincident` と表示されます。その `Object` では線分、円弧、開いたポリライン、スプラインを選択でき、原点はクリックした位置に近い方の端点に、Z 軸はオブジェクトに沿って外向きになります。

## まだできないこと [#missing]

UCS をソリッドの面に位置合わせする `Face` は、面を尋ねますが、まだ面を見つけられません。最初のプロンプトに表示される Apply と SEction は、ビューポートが 1 つで断面オブジェクトもないため、ここでは受け付けられません。UCS ダイアログ(UCSMAN)、アイコンのグリップと右クリック メニュー、配置中に新しい UCS を示すアイコンもありません。クロスヘア カーソルは UCS とともに回転せず、[`PLAN`](/docs/commands/plan) でビューを UCS に合わせるまで画面上で直立したままです。UCSFOLLOW、UCSVP、ダイナミック UCS もありません。寸法への `OBject`、選択時のグループもできません。正投影 UCS が保持する深さもありません。長い一覧での一時停止(Press ENTER to continue)もありません。

## よくある質問 [#questions]

### AutoCAD で UCS をワールドに戻すには?

UCS を実行して[Enter]を押します。既定値は `World` です。図面を再び真上から見るには、[`PLAN`](/docs/commands/plan) を実行して `World` を選びます。

### AutoCAD で UCS を回転させるには?

UCS を実行し、`Z` を選んで角度を入力します。`30` で X 軸と Y 軸が反時計回りに 30° 回転します。`X` と `Y` は XY 平面を立ち上げ、既定は 90° です。

### UCS と WCS の違いは?

ワールド座標系(WCS)は決して動きません。ユーザ座標系(UCS)は、ユーザが移動したり回転させたりする座標系です。最初は両者が同じで、UCS は現在の座標系が `*WORLD*` だと表示します。入力した座標は UCS で読み取られ、作図したものは UCS の XY 平面上に置かれます。

### 3D ソリッドの面に作図するには?

UCS をその面に移動します。直方体の上面なら原点だけで十分です。このセッションのように、UCS、上面の角、[Enter]の順に指定します。側面では 3 点を指定します。原点を角に、X 軸方向をエッジに沿った点で、Y 軸方向を面上のもう 1 点で指定します。その後に作図したものは、その面上に置かれます。
