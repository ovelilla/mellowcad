BLOCK[ブロック登録]コマンドは、一連のオブジェクトを名前を付けて図面に保存します。[`INSERT`](/docs/commands/insert) で何度でも配置でき、配置したものはそれぞれ、その 1 つの定義への参照になります。名前、次に挿入基点(各参照を配置する基準点)、次にオブジェクトを尋ねます。[Enter]で選択を終えるとブロックが定義され、選択したオブジェクトはその位置でブロックの参照になります。コマンド全体が 1 ステップで、元に戻すで取り消せます。

AutoCAD の BLOCK は[ブロック定義]ダイアログを開きますが、MellowCAD にはこのダイアログがありません。ここでは BLOCK は、AutoCAD のコンソール版と同じく、`-BLOCK` と同じことをコマンド ラインで尋ねます。名前にはスペースを含めることができ、最大 255 文字ですが、`< > / \ " : ; ? * | , =` とバッククォートは使えません。[Enter]だけを押すか、このような名前を入力すると `Invalid block name.` と表示され、もう一度尋ねられます。図面に既にある名前(大文字と小文字は区別されません)を入力すると、そのブロックを再定義するかどうかを、`Yes` または `No`(既定、コマンドを終了します)で尋ねられます。

- **コマンド：** `BLOCK`
- **短縮コマンド：** `B`, `ACADBLOCKDIALOG`, `BMAKE`, `BMOD`
- **パネル：** [整理](/docs/commands#organize)
- **試す：** [エディタを開き](/ja/draw)、`B` と入力して\[Enter\]を押します。

## オプション [#options]

### `?` [#list]

図面内のブロックを一覧表示します。一覧表示するブロックを尋ね(既定はすべてを表す `*`、またはワイルドカードを含む名前)、一致する名前と種類ごとの数を表示して終了します。配列複写のブロックなどの匿名ブロックは数には含まれますが、名前は表示されません。

## まだできないこと [#missing]

AutoCAD の[ブロック定義]ダイアログ(BLOCK はコマンド ラインで尋ねます)。基点での異尺度対応(Annotative)とモード(Mode)オプション(保持、削除)。オブジェクトは常にブロック参照に変換されます。属性値のボックスを省略する ATTREQ 0 と、ATTSYNC、ATTREDEF、BATTMAN、BATTORDER。再定義したブロックの参照の属性は、AutoCAD と同じくそのまま残ります。ByBlock もありません。ブロック内のオブジェクトは、AutoCAD で ByBlock で作図したオブジェクトのように、参照自体の色、線種、線の太さを取ることができません。回転した UCS では AutoCAD 2027 は変換するオブジェクトを移動しますが、ここでは意図的に元の位置のままにしています。

## よくある質問 [#questions]

### AutoCAD のブロック登録の短縮コマンドは?

`B` と入力し、[Enter]または[Space]を押します。AutoCAD では[ブロック定義]ダイアログが開きますが、ここでは `-B`(`-BLOCK`)と同じくコマンド ラインで尋ねます。AutoCAD のどの言語版でも `_BLOCK` が使えます。

### AutoCAD でブロックを作成するには?

`B` と名前を入力し、基点(角や、ブロックを置く辺の中点など)を指定して、オブジェクトを選択します。[Enter]でブロックが定義され、オブジェクトはその参照に変わります。コマンドの前に選択したオブジェクトも、基点の後で使われます。

### ブロックを再定義するには?

ブロックの名前で BLOCK を実行して `Yes` と答え、基点を指定して新しいオブジェクトを選択します。そのブロックのすべての参照に新しい定義が表示されます。オブジェクトにそのブロック自体の参照を含めることはできません。そのような選択は受け付けられず、コマンドが終了します。

### 属性付きのブロックを作成するには?

先に [`ATTDEF`](/docs/commands/attdef) で属性を定義し、ほかのオブジェクトと一緒に選択します。属性は選択した順にブロックに含まれます。オブジェクトに置き換わる参照では、属性ごとのフィールドを持つボックスが開きます。ラベルはプロンプト、値は既定値で、[Enter]で値が適用され、[Esc]では既定値のままになります。

### ブロックを分解するには?

[`EXPLODE`](/docs/commands/explode) で、参照が表示しているオブジェクトに戻ります。ネストは 1 レベルずつ分解され、各オブジェクトはそれぞれの画層と色になります。属性は属性定義に戻り、値は失われます。
