ATTEDIT changes the attribute values of one block reference. It asks you to select the reference, then opens a box with a field for each of its attributes, labelled by the attribute's prompt and filled with its value, as AutoCAD's Edit Attributes dialog is. Retype the values, Tab moving from one field to the next, and Enter, AutoCAD's OK, applies them in one step that `U` takes back; Escape, its Cancel, changes nothing.

The pick takes the object under the box. Anything but a block reference is refused, and so is a reference whose block has no attributes, and the question is asked again; a pick on nothing asks again in silence. The block's definition is not changed, nor are its other references: each holds values of its own. [`EATTEDIT`](/docs/commands/eattedit) edits the same values in a box labelled by tag, and a double-click on a reference with attributes runs it.

- **Command:** `ATTEDIT`
- **Aliases:** `ATE`, `DDATTE`
- **Panel:** [Organize](/docs/commands#organize)
- **Try it:** [Open the editor](/draw), type `ATE` and press Enter.

## Questions [#questions]

### What is the shortcut for ATTEDIT in AutoCAD?

`ATE`, then Enter or Space; `DDATTE` too. `_ATTEDIT` works in any language of AutoCAD.

### How do I edit block attributes in AutoCAD?

Type `ATE` and pick the reference, or double-click it, which runs [`EATTEDIT`](/docs/commands/eattedit). Change the values in the box and press Enter. To change the attributes themselves, their tag, prompt or position, edit the definitions and redefine the block with [`BLOCK`](/docs/commands/block).

### Why does ATTEDIT say the block has no editable attributes?

Because the block of the reference you picked holds no attributes: ATTEDIT edits the values of a reference to a block that has them. A definition that has not joined a block yet is edited with [`TEXTEDIT`](/docs/commands/textedit), a double-click on it.

### What is the difference between ATTEDIT and EATTEDIT?

Both edit one reference's values. ATTEDIT's box labels each field by the attribute's prompt, as AutoCAD's Edit Attributes dialog does; [`EATTEDIT`](/docs/commands/eattedit)'s, the Enhanced Attribute Editor, by its tag. In AutoCAD, EATTEDIT also has tabs for each attribute's text options and properties.
