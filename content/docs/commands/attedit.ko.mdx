ATTEDIT(속성 편집) 명령은 블록 참조 하나의 속성 값을 바꿉니다. 참조를 선택하라고 묻고, AutoCAD의 속성 편집 대화상자처럼 속성마다 필드가 있는 상자를 엽니다. 각 필드에는 속성의 프롬프트가 이름으로 붙고 현재 값이 채워져 있습니다. 값을 다시 입력하고 Tab 키로 다음 필드로 옮기며, AutoCAD의 확인에 해당하는 Enter 키는 `U` 명령으로 되돌릴 수 있는 한 단계로 값을 적용합니다. 취소에 해당하는 Esc 키는 아무것도 바꾸지 않습니다.

선택 상자 아래의 객체를 선택합니다. 블록 참조가 아닌 객체와 블록에 속성이 없는 참조는 거부되고 다시 묻습니다. 아무것도 없는 곳을 선택하면 메시지 없이 다시 묻습니다. 블록 정의와 다른 참조는 바뀌지 않습니다. 각 참조는 고유한 값을 갖습니다. [`EATTEDIT`](/docs/commands/eattedit) 명령은 태그로 이름 붙은 상자에서 같은 값을 편집하며, 속성이 있는 참조를 두 번 클릭하면 실행됩니다.

- **명령:** `ATTEDIT`
- **단축키:** `ATE`, `DDATTE`
- **패널:** [구성](/docs/commands#organize)
- **해 보기:** [편집기를 열고](/ko/draw) `ATE` 입력 후 Enter 키를 누릅니다.

## 아직 지원하지 않는 것 [#missing]

속성을 하나씩 또는 전역으로 편집하는 명령행 버전 `-ATTEDIT`와 그 단축키 `-ATE`, `ATTE`가 없습니다. 한 페이지에 들어가지 않는 속성이 있는 블록을 위한 속성 편집의 이전과 다음 버튼, 블록 이름 줄이 없습니다. 속성 하나를 제자리에서 편집하는 ATTIPEDIT와 그 Ctrl+두 번 클릭이 없습니다. 참조에서 잠기지 않은 속성 자체의 그립과 특성 팔레트의 속성 행이 없습니다.

## 자주 묻는 질문 [#questions]

### 오토캐드 속성 편집 단축키는 무엇입니까?

`ATE`를 입력하고 Enter 키나 Space 키를 누릅니다. `DDATTE`도 됩니다. AutoCAD의 어느 언어 버전에서든 `_ATTEDIT`도 됩니다.

### 오토캐드에서 블록 속성을 편집하려면 어떻게 합니까?

`ATE`를 입력하고 참조를 선택하거나, 참조를 두 번 클릭하여 [`EATTEDIT`](/docs/commands/eattedit) 명령을 실행합니다. 상자에서 값을 바꾸고 Enter 키를 누릅니다. 태그, 프롬프트, 위치처럼 속성 자체를 바꾸려면 정의를 편집하고 [`BLOCK`](/docs/commands/block) 명령으로 블록을 재정의합니다.

### ATTEDIT가 블록에 편집할 수 있는 속성이 없다고 하는 이유는 무엇입니까?

선택한 참조의 블록에 속성이 없기 때문입니다. ATTEDIT는 속성이 있는 블록의 참조 값을 편집합니다. 아직 블록에 들어가지 않은 정의는 두 번 클릭하여 [`TEXTEDIT`](/docs/commands/textedit) 명령으로 편집합니다.

### ATTEDIT와 EATTEDIT의 차이는 무엇입니까?

둘 다 참조 하나의 값을 편집합니다. ATTEDIT의 상자는 AutoCAD의 속성 편집 대화상자처럼 각 필드에 속성의 프롬프트를 붙이고, 고급 속성 편집기인 [`EATTEDIT`](/docs/commands/eattedit) 명령의 상자는 태그를 붙입니다. AutoCAD의 EATTEDIT에는 각 속성의 문자 옵션과 특성을 위한 탭도 있습니다.
