SPHERE[球]コマンドは、3D ソリッドの球を作成します。中心を指定してから半径を指定します。マウスで指定した半径は中心を通る平面上で読み取られます。前回の半径が既定値として表示され、[Enter]で使われます。この値は [`CYLINDER`](/docs/commands/cylinder)、[`CONE`](/docs/commands/cone) などのプリミティブと共通です。球は現在の画層に作成され、1 回の操作で元に戻せます。

2D ワイヤフレームと隠線処理では、球は線で表示されます。`ISOLINES` の数だけの経線と緯線で、スナップできるのは中心だけです。[`LIST`](/docs/commands/list) で位置と半径がわかり、プロパティ パレットで半径または直径を入力できます。グリップで移動でき、赤道の 4 分の 1 ごとにあるグリップで半径を変えられます。[`UNION`](/docs/commands/union)、[`SUBTRACT`](/docs/commands/subtract) など、MellowCAD の 3D で 3D ソリッドとして扱えます。MellowCAD の 3D はソリッドのみで、まだ部分的な対応です。

- **コマンド：** `SPHERE`
- **パネル：** [作成](/docs/commands#draw)
- **試す：** [エディタを開き](/ja/draw)、`SPHERE` と入力して\[Enter\]を押します。

## オプション [#options]

### `3P` [#3p]

中心のプロンプトで、3 点を尋ねます。球の中心はその 3 点を通る円の中心になり、半径もその円の半径になります。

### `2P` [#2p]

中心のプロンプトで、直径の両端を尋ねます。空間のどこにでも指定できます。

### `Ttr` (`T`) [#ttr]

中心のプロンプトで、接線スナップを使って線分、円、円弧を 2 つ選択し、半径を指定します。中心は、両方に接するその半径の円の中心で、それらの高さに置かれます。

### `Diameter` (`D`) [#diameter]

半径のプロンプトで、代わりに直径を尋ねます。前回の半径の 2 倍が既定値になります。

## まだできないこと [#missing]

AutoCAD では球の [`EXPLODE`](/docs/commands/explode) でサーフェスになりますが、MellowCAD にはサーフェスがないため、分解できないと表示されます。ホット グリップからの移動、回転、尺度変更、鏡像と、専用の 3D コマンド(3DSCALE)はありません。移動と回転は `3DMOVE` と `3DROTATE` で行えます。AutoCAD の `DISPSILH` が描く輪郭線もありません。[`VSCURRENT`](/docs/commands/vscurrent) の表示スタイルは 2D ワイヤフレーム、隠線処理、コンセプト以外はありません。

## よくある質問 [#questions]

### AutoCAD で球を作るには?

SPHERE を実行し、中心、次に半径を指定します。`0,0,0` と `25` で、このセッションの球になります。球として見るには、ViewCube の角をクリックするか、`-VIEW` と `SEIso` でビューを回転させます。

### 球が線の入った円に見えるのはなぜ?

2D ワイヤフレームと隠線処理では、球が経線と緯線で描かれ、平面図では円とそれを通る線に見えます。[`VSCURRENT`](/docs/commands/vscurrent) で `Conceptual` を選ぶと陰影が付き、`ISOLINES` で表示する線の数を設定できます。

### 半球を作るには?

球を作成し、[`SLICE`](/docs/commands/slice) で中心を通るように切断します。平面上の 3 点を指定するか、`XY` を選んで中心を指定し、残す側を指定します。

### 直径で球を作るには?

半径のプロンプトで `Diameter` を選び、直径を入力します。`2P` で直径の両端を指定しても作成できます。
