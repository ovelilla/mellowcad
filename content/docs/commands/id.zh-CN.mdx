ID（点坐标）命令写出一个点的坐标。在 `Specify point:` 提示下拾取、捕捉或输入该点，ID 在命令行中用一行写出其 X、Y、Z 坐标，然后结束。数值以当前 UCS 表示，按图形的精度显示。使用对象捕捉时，Z 为对象在该点的高度；否则为标高平面的 Z 值。按 Enter 键结束命令，不显示任何信息；执行 ID 前选定的对象在命令开始时取消选择。以撇号输入（`'ID`）时，可以在其他命令中透明使用，之后继续执行该命令。

- **命令：** `ID`
- **面板：** [查询与视图](/docs/commands#inquiry)
- **试一试：** [打开编辑器](/zh-cn/draw)，输入 `ID`，然后按 Enter 键。

## 常见问题 [#questions]

### CAD的 ID 命令有什么用？

它报告一个点的位置：在当前 UCS 中的 X、Y、Z 坐标。它不绘制也不修改任何对象。

### CAD怎么查看一个点的坐标？

输入 `ID`，然后使用端点或圆心等对象捕捉单击该点，使其准确落在点上。坐标写在命令行中。

### CAD怎么查看点的 Z 坐标？

用对象捕捉捕捉到该点：ID 写出对象在该处的 Z 值。直接单击得到的是标高平面的 Z 值，除非 ELEVATION 或 UCS 将其抬高，否则为 0。

### ID 显示的坐标为什么和预期不一样？

ID 按当前 UCS 读取坐标。如果 UCS 已移动或旋转，数值从其原点沿其坐标轴测量：用 [`UCS`](/docs/commands/ucs) 的“世界”选项恢复后即可读取世界坐标。
