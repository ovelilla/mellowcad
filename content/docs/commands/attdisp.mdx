ATTDISP sets which attributes the block references in the drawing show. It asks for the setting, offering the current one, Normal in a new drawing; any other word says the keyword is invalid and asks again, and Enter keeps it. A change redraws the whole drawing, `Regenerating model.` as AutoCAD 2027 says it, and is saved with the drawing as ATTMODE, a step that `U` takes back. Typed with an apostrophe inside a command, it runs there too.

It changes only what shows: an invisible attribute keeps its value, and a hidden one can still be edited with [`ATTEDIT`](/docs/commands/attedit) or [`EATTEDIT`](/docs/commands/eattedit).

- **Command:** `ATTDISP`
- **Panel:** [Organize](/docs/commands#organize)
- **Try it:** [Open the editor](/draw), type `ATTDISP` and press Enter.

## Options [#options]

### `Normal` (`N`) [#normal]

Shows each attribute as it was defined: the visible ones, not those defined with [`ATTDEF`](/docs/commands/attdef)'s `Invisible`.

### `ON` [#on]

Shows every attribute, the invisible ones too.

### `OFF` (`OF`) [#off]

Hides every attribute, the visible ones too.

## Questions [#questions]

### How do I show invisible attributes in AutoCAD?

Type `ATTDISP` and choose `ON`: every attribute shows, the invisible ones too. `Normal` hides them again.

### Why are my block attributes not showing?

`ATTDISP` may be `OFf`, which hides every attribute, or `Normal` with the attributes defined as invisible. Choose `ON` to see them all. A reference whose block has no attributes shows none, whatever the setting.

### How do I hide attribute values in AutoCAD?

Define them invisible: [`ATTDEF`](/docs/commands/attdef)'s `Invisible` mode, before you make the block. ATTDISP `OFf` hides every attribute at once, in the whole drawing.
