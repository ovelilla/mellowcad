ID[位置表示]コマンドは、点の座標を表示します。`Specify point:` で点をクリック、スナップ、または入力すると、ID はその X、Y、Z をコマンド ラインに 1 行で表示して終了します。値は現在の UCS で、図面の精度で表示されます。オブジェクト スナップを使うと Z はその点でのオブジェクトの高さになり、それ以外では高度の平面の Z になります。[Enter]を押すと何も表示せずに終了し、ID の前に選択したオブジェクトは開始時に選択解除されます。アポストロフィを付けて `'ID` と入力すると別のコマンドの実行中に実行でき、その後元のコマンドが続きます。

- **コマンド：** `ID`
- **パネル：** [問い合わせとビュー](/docs/commands#inquiry)
- **試す：** [エディタを開き](/ja/draw)、`ID` と入力して\[Enter\]を押します。

## よくある質問 [#questions]

### AutoCAD の ID コマンドとは?

点の位置、つまり現在の UCS での X、Y、Z を表示します。何も作図せず、何も変更しません。

### 点の座標を確認するには?

`ID` と入力し、端点や中心などのオブジェクト スナップを使って点をクリックすると、正確にその点に合わせられます。座標はコマンド ラインに表示されます。

### 点の Z 座標を確認するには?

オブジェクト スナップでその点にスナップします。ID はその位置でのオブジェクトの Z を表示します。単にクリックすると高度の平面の Z になり、ELEVATION や UCS で上げていなければ 0 です。

### ID で予想と違う座標が表示されるのはなぜ?

ID は現在の UCS で読み取ります。UCS を移動または回転した場合、数値はその原点から UCS の軸に沿って測られます。ワールド座標を読み取るには、[`UCS`](/docs/commands/ucs) の World オプションを使います。
