INSERT（插入圖塊）指令將圖面中定義的圖塊放置為參考：再多一個複本，擁有自己的點、比例與旋轉，由 [`BLOCK`](/docs/commands/block) 建立的同一個定義繪製。與 AutoCAD 2027 的 INSERT 一樣，指令會開啟「圖塊」選項板，顯示圖面中的圖塊；按一下其中一個，指令行就會要求指定其插入點，圖塊隨游標拖曳，接著詢問比例與旋轉。選項板保持開啟，因此只要逐一按一下，就能一個接一個插入圖塊。

`-INSERT` 則全部在指令行中詢問：圖塊名稱（按 Enter 採用提供的名稱：上次插入的圖塊，否則為最後定義的圖塊）、插入點，接著是 X 比例係數、Y 比例係數（按 Enter 採用 X 的值）與旋轉角度。負的比例係數會反轉圖塊，不相等的比例係數則會拉伸圖塊：其中的圓會繪製為橢圓。含有屬性的圖塊接著會依各屬性的提示詢問其值，並提供其預設值。圖塊中位於圖層 0 的物件採用參考的圖層，其他物件保留各自的圖層。每次插入是一個步驟，退回一次即可復原。

- **指令：** `INSERT`
- **快捷鍵：** `I`
- **面板：** [組織](/docs/commands#organize)
- **試試看：** [開啟編輯器](/zh-tw/draw)，輸入 `I` 並按 Enter。

## 選項 [#options]

### `?` [#list]

在圖塊名稱提示下：列出圖面中的圖塊，與 [`BLOCK`](/docs/commands/block) 相同，然後結束。

### `Scale` (`S`) [#scale]

在插入點提示下：要求輸入適用於兩個軸的一個比例係數，再次要求指定插入點，圖塊以該大小拖曳。指定點之後不再詢問 X 與 Y 比例係數。

### `Rotate` (`R`) [#rotate]

在插入點提示下：要求輸入角度（直接輸入或以兩點指定），再次要求指定插入點，圖塊以旋轉後的方向拖曳。指定點之後不再詢問旋轉角度。

## 常見問題 [#questions]

### AutoCAD 插入圖塊指令的快捷鍵是什麼？

輸入 `I`，再按 Enter 或空白鍵：與 AutoCAD 2027 一樣會開啟「圖塊」選項板。`-I` 是 `-INSERT`，在指令行中詢問。`_INSERT` 在任何語言版本的 AutoCAD 中都適用。

### 如何從指令行插入圖塊？

輸入 `-I` 與圖塊名稱，然後點選插入點並回答比例與旋轉，按 Enter 即保留各預設值。在名稱提示下輸入 `?` 會列出現有的圖塊。

### 如何以不同比例插入圖塊？

在插入點之後輸入 X 比例係數，並在 Y 比例係數提示下按 Enter 使兩者相等；或在指定點之前選擇 `Scale`，輸入適用於兩個軸的一個比例係數。負的比例係數會鏡射圖塊。

### 如何插入另一個圖面中的圖塊？

無法從其檔案插入：INSERT 只放置圖面中定義的圖塊。請改為複製其參考（Ctrl+C），開啟要放置圖塊的圖面並貼上（Ctrl+V）：其圖塊會一併帶入，除非該圖面已有同名的圖塊，此時保留原有的定義。
