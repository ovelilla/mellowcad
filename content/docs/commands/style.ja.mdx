STYLE[文字スタイル管理]コマンドは、図面の文字スタイル、つまり文字を何で書くかを管理します。文字、マルチ テキスト、属性はそれぞれスタイルを持ち、新しいものには現在のスタイルが適用されます。新しい図面では Standard です。AutoCAD の STYLE は[文字スタイル管理]ダイアログを開きますが、MellowCAD にはまだないため、STYLE は[スタイル]パレットの文字の表を開きます。このパレットには [`DIMSTYLE`](/docs/commands/dimstyle) の寸法スタイルもあります。ダイアログと同様に、実行前の選択は解除されます。コマンドの実行中にアポストロフィを付けて `'STYLE` と入力すると、そのコマンドを終了せずに開きます。

表にはスタイルが一覧表示され、現在のスタイルに印が付きます。[新規作成]は選択したスタイルのコピーを、空いている最初の名前 `style1`、`style2`… で作成し、現在のスタイルにします。[現在に設定]はスタイルを現在のスタイルにします。スタイルの名前は入力し直せます。AutoCAD と同様に、大文字・小文字を問わず、すでに使われている名前は受け付けられません。[削除]はスタイルを削除しますが、Standard、現在のスタイル、使用中のスタイルは削除できません。[高さ]はスタイルに固定の高さを与えます。既定の 0 では高さが固定されず、[`TEXT`](/docs/commands/text) が毎回高さを尋ねます。高さを設定すると、TEXT は尋ねません。どの変更も 1 回の操作で、`U` で元に戻せます。文字を選択している場合は、プロパティ パレットの[文字スタイル]の行で、1 回の操作で別のスタイルを適用できます。

- **コマンド：** `STYLE`
- **短縮コマンド：** `ST`, `DDSTYLE`
- **パネル：** [注釈](/docs/commands#annotate)
- **試す：** [エディタを開き](/ja/draw)、`ST` と入力して\[Enter\]を押します。

## まだできないこと [#missing]

[文字スタイル管理]ダイアログとそのプレビューはなく、STYLE は代わりに[スタイル]パレットを開きます。フォント、フォント スタイル、ビッグフォント、幅係数、傾斜角度、[上下反転]、[左右反転]、[縦書き]の効果もありません。どのスタイルも Arial で、傾きなし、幅 1 で描かれます。異尺度対応スタイルと、AutoCAD の新しい図面に Standard とともに含まれる Annotative スタイルもありません。すべてをコマンド ラインで尋ねる `-STYLE` もありません。

## よくある質問 [#questions]

### AutoCAD の STYLE の短縮コマンドは?

`ST` と入力し、[Enter]または[Space]を押します。`DDSTYLE` も使えます。`_STYLE` は AutoCAD のどの言語版でも使えます。

### AutoCAD で文字スタイルを変更するには?

新しい文字には、STYLE で開く[スタイル]パレット、または [`TEXT`](/docs/commands/text) の `Style` オプションでスタイルを現在のスタイルにします。記入済みの文字は、選択してプロパティ パレットの[文字スタイル]の行でスタイルを選びます。

### 文字スタイルのフォントを変更するには?

AutoCAD では[文字スタイル管理]ダイアログの[フォント名]で変更します。ここではまだできません。どのスタイルも Arial で描かれ、スタイルの違いは名前と高さだけです。

### TEXT で高さを聞かれないのはなぜ?

現在の文字スタイルに固定の高さが設定されています。[スタイル]パレットでその高さを 0 にすると、[`TEXT`](/docs/commands/text) が再び高さを尋ね、前回の高さを既定値として表示します。
