TRIM cuts an object back to where other objects cross it: you pick the piece to take away, and it goes up to the nearest crossing on either side. It starts in Quick mode, as AutoCAD's does: every object is a cutting edge, and an object that nothing crosses is deleted whole. Holding Shift as you pick extends the object to the nearest edge instead, as [`EXTEND`](/docs/commands/extend) does. Each pick is one step that Undo takes back; Enter ends the command.

- **Command:** `TRIM`
- **Aliases:** `TR`
- **Panel:** [Modify](/docs/commands#modify)
- **Try it:** [Open the editor](/draw), type `TR` and press Enter.

## Options [#options]

### `cuTting edges` (`T`) [#cutting]

Chooses which objects cut: select them, or press Enter to take every object. From then on only those cut, whatever the mode, until the command ends.

### `Fence` (`F`) [#fence]

Asks for the points of a line, as many as you like until Enter: every object it crosses is trimmed where it crosses, in one step. Standard mode lists it; Quick mode takes it too, and a pick on nothing there starts a two-point fence by itself.

### `Crossing` (`C`) [#crossing]

Asks for the two corners of a window: everything its outline crosses is trimmed, in one step. An object wholly inside the window is not one it crosses.

### `mOde` (`O`) [#mode]

Switches between `Quick` and `Standard`. In Standard mode TRIM first asks for the cutting edges (Enter takes them all), leaves an object that no edge crosses with `Does not intersect with the cutting edge.`, lists Fence and Edge, and a pick on nothing starts a crossing window. The mode is TRIM's and EXTEND's both, and lasts the session.

### `Edge` (`E`) [#edge]

Standard mode only. With `Extend`, an edge also cuts where it would cross if it were extended — a line both ways, an arc round its circle; `No extend` is the default.

### `eRase` (`R`) [#erase]

Erases objects without leaving the command: select them, then Enter erases them, as one step of TRIM's that Undo can take back.

### `Undo` (`U`) [#undo]

Listed once the prompt has had an answer — a pick, a fence, a window: takes back the last trim, and with nothing left to take back says so.

## What it does not do yet [#missing]

Project: AutoCAD's projection option (None, Ucs, View) is not offered, and everything is worked out projected on the UCS's XY plane, which is AutoCAD's default, Ucs. A fence cannot be dragged with the cursor yet, only picked point by point. The trim mode and Edge's choice last the session, where AutoCAD keeps them from one session to the next. An object at an angle to the UCS, a spline aside, neither cuts nor is trimmed.

## Questions [#questions]

### What is the shortcut for TRIM in AutoCAD?

`TR`, then Enter or Space. The full name works too, and `_TRIM` in any language of AutoCAD.

### Why does TRIM delete the whole line?

Because TRIM is in Quick mode, AutoCAD's default since its 2021 release: a pick on an object that no edge crosses deletes it. Choose `mOde` and then `Standard` to have TRIM leave it and say so instead.

### How do I trim many lines at once?

Pick on an empty spot and pick a second point: every object that fence crosses is trimmed in one step. Or choose `Crossing` and draw a window over the pieces to remove.

### How do I extend a line with TRIM?

Hold Shift as you pick the line near the end to extend: it grows to the nearest edge, as with [`EXTEND`](/docs/commands/extend), and the next pick without Shift trims again.
