ATTECRAN (ATTDISP en anglais) définit quels attributs affichent les références de bloc du dessin. Elle demande le paramètre, en proposant le paramètre courant, Normal dans un nouveau dessin ; tout autre mot est signalé comme option incorrecte et la question revient, et Entrée conserve le paramètre. Un changement redessine tout le dessin, `Régénération du modèle.` comme le dit AutoCAD 2027, et est enregistré avec le dessin dans ATTMODE, une étape que `U` annule. Tapée avec une apostrophe à l'intérieur d'une commande, elle s'y exécute aussi.

Elle ne change que ce qui s'affiche : un attribut invisible garde sa valeur, et un attribut masqué peut toujours être modifié avec [`ATTEDIT`](/docs/commands/attedit) ou [`EATTEDIT`](/docs/commands/eattedit).

- **Commande :** `ATTECRAN`
- **En anglais :** `ATTDISP`, tapé `_ATTDISP` dans toutes les langues
- **Groupe :** [Organisation](/docs/commands#organize)
- **Essayez-la :** [Ouvrez l'éditeur](/fr/draw), tapez `ATTECRAN` et appuyez sur Entrée.

## Options [#options]

### `Normal` (`N`) [#normal]

Affiche chaque attribut tel qu'il a été défini : les attributs visibles, et non ceux définis avec le mode `Invisible` d'[`ATTDEF`](/docs/commands/attdef).

### `ACtif` (`AC`) [#on]

Affiche tous les attributs, les invisibles aussi.

### `INactif` (`IN`) [#off]

Masque tous les attributs, les visibles aussi.

## Questions [#questions]

### Comment afficher les attributs invisibles dans AutoCAD ?

Tapez `ATTECRAN` et choisissez `ACtif` : tous les attributs s'affichent, les invisibles aussi. `Normal` les masque de nouveau.

### Pourquoi les attributs de mon bloc ne s'affichent pas ?

`ATTECRAN` est peut-être sur `INactif`, qui masque tous les attributs, ou sur `Normal` avec des attributs définis comme invisibles. Choisissez `ACtif` pour les voir tous. Une référence dont le bloc n'a pas d'attributs n'en affiche aucun, quel que soit le paramètre.

### Comment masquer les valeurs d'attribut dans AutoCAD ?

Définissez-les invisibles : le mode `Invisible` d'[`ATTDEF`](/docs/commands/attdef), avant de créer le bloc. ATTECRAN `INactif` masque tous les attributs à la fois, dans tout le dessin.
