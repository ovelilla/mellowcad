ARRAYPATH copies a selection along a path, a line, an arc, a circle or a polyline, as one array object. It asks for the objects, says the type and whether the array is associative, asks for the path curve and shows the array at once: the items one and a half times the selection's size apart, as many as fit along the path, each turned as the path turns. An open path runs from the end nearer your pick, a circle counter-clockwise from its angle 0. Then one prompt edits the array live until Enter makes it, through its options or the preview's grips, as in AutoCAD. The objects selected stay where they are, as its first item.

- **Command:** `ARRAYPATH`
- **Panel:** [Modify](/docs/commands#modify)
- **Try it:** [Open the editor](/draw), type `ARRAYPATH` and press Enter.

## Options [#options]

### `ASsociative` (`AS`) [#associative]

`Yes`, the default, makes one array object, which its grips and the Properties palette change later; `No` makes separate copies beside the objects selected. The answer is kept for the session, by ARRAYRECT and ARRAYPOLAR too.

### `Method` (`M`) [#method]

`Measure`, the default, sets the items a distance apart, as many as fit; `Divide` spreads a number of items evenly over the whole path, one at each end of an open path.

### `Items` (`I`) [#items]

By Divide, the number of items. By Measure, the distance between them, then how many, up to the most that fit, which it says; `Fill` takes them all.

### `Align items` (`A`) [#align-items]

`Yes`, the default, turns each item as the path turns from its start; `No` only moves it along.

### `eXit` (`X`) [#exit]

Makes the array and ends the command, as Enter does.

## What it does not do yet [#missing]

The array does not follow its path: edit the path later and the array keeps the one it was made on. Splines, ellipses and 3D polylines cannot be paths yet, nor a path out of the UCS's plane. Base point, Tangent direction, Rows, Levels, Z direction and Expression are not offered, nor a group at the path prompt, and the array's grips have no menus.

## Questions [#questions]

### How do I array objects along a curve?

Type `ARRAYPATH`, select the objects, press Enter and pick the path near the end to start from; or type `AR` for [`ARRAY`](/docs/commands/array) and choose `PAth` after the objects. Then set the spacing or the number of items, and press Enter to make it.

### Why doesn't my path array follow the path?

Here an array keeps the path as it was when the array was made: move or stretch the path later and the array stays as it is, where AutoCAD's associative path array would follow it. Erasing the path leaves the array too. If the items do not turn with the path, choose `Align` and answer `Yes`.

### How do I change the direction of a path array?

Pick the path near its other end: an open path runs from the end nearer the pick. A circle always runs counter-clockwise from its angle 0.

### How do I space items evenly along the whole path?

Choose `Method`, then `Divide`, then `Items` and type how many: they are spread evenly, the first and the last at the ends of an open path.
