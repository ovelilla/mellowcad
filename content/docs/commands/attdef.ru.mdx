Команда АТОПР (ATTDEF) определяет атрибут: тег, подсказку и значение по умолчанию, размещенные в чертеже строкой текста. Выберите его вместе с другими объектами, когда создаете блок командой [`БЛОК`](/docs/commands/block), и каждое вхождение этого блока хранит для него собственное значение: номер двери, код детали, название помещения. До тех пор определение показывает свой тег.

В AutoCAD команда АТОПР открывает диалоговое окно «Определение атрибутов», которого в MellowCAD нет: здесь она запрашивает в командной строке то же, что и `-АТОПР`, как в консоли AutoCAD. Команда сообщает текущие режимы и предлагает изменить один из них, пока Enter не переведет дальше. Затем тег: без пробелов, так как пробел завершает ввод, а строчные буквы становятся прописными; Enter без текста выводит `Тег не может быть пустым`. Затем подсказка, по которой [`ВСТАВИТЬ`](/docs/commands/insert) будет запрашивать значение (Enter подставляет тег), и значение по умолчанию. Последним задается положение текста — теми же вопросами, что у команды [`ТЕКСТ`](/docs/commands/text): начальная точка, высота и угол поворота. Высота и выравнивание у нее общие с командой ТЕКСТ: изменение в одной действует и в другой. Enter в ответ на запрос начальной точки ставит определение на строку ниже последнего определенного, с его высотой, поворотом, стилем и выравниванием, так что атрибуты блока выстраиваются один под другим.

- **Команда:** `АТОПР`
- **На английском:** `ATTDEF`, в любом языке вводится как `_ATTDEF`
- **Псевдонимы:** `АТ`, `ДИАЛАТОП`
- **Панель:** [Организация](/docs/commands#organize)
- **Попробовать:** [Откройте редактор](/ru/draw), введите `АТ` и нажмите Enter.

## Параметры [#options]

### `Скрытый` (`С`) [#invisible]

Значение не показывается во вхождениях, пока команда [`АТЭКР`](/docs/commands/attdisp) не включит его показ. Каждый режим — переключатель: выбор переключает его между `Д` и `Н`, снова выводит режимы и повторяет запрос. Режимы сохраняются для следующего запуска команды АТОПР.

### `Постоянный` (`П`) [#constant]

Все вхождения хранят одно и то же значение, которое команда АТОПР запрашивает вместо подсказки и значения по умолчанию; команда ВСТАВИТЬ его никогда не запрашивает.

### `Контролируемый` (`К`) [#verify]

Команда ВСТАВИТЬ запрашивает значение повторно для проверки — после того как запросит все значения по одному разу.

### `Установленный` (`У`) [#preset]

Команда ВСТАВИТЬ не запрашивает значение: каждое вхождение получает значение по умолчанию.

### `Фиксированное положение` (`Ф`) [#lock-position]

Изначально включен: атрибут остается там, куда его ставит блок.

### `Выравнивание` (`В`) [#justify]

Запрашивает, как текст выравнивается относительно своей точки, так же как команда ТЕКСТ: `сЛева`, `Центр`, `впРаво`, `сЕредина` или одна из девяти точек — вверху, в середине и внизу, слева, по центру и справа. Затем запрос начальной точки просит указать выбранную точку: вариант `СЦ` (середина по центру) помещает значение в центр марки.

### `Стиль` (`С`) [#style]

Запрашивает текстовый стиль, который становится текущим; `?` выводит список стилей чертежа.

## Вопросы [#questions]

### Как называется команда атрибутов на английском и какое у нее сокращение?

По-английски ATTDEF, в русском AutoCAD АТОПР: введите `АТ`, затем нажмите Enter или Пробел; `ДИАЛАТОП` тоже работает. `-АТ` — это `-АТОПР`, вариант для командной строки, который здесь выполняет и команда АТОПР. `_ATTDEF` работает в любой языковой версии AutoCAD.

### Как создать блок с атрибутами в AutoCAD?

Нарисуйте символ, затем запустите команду АТОПР для каждого атрибута и поместите его текст туда, где должно показываться значение. Запустите команду [`БЛОК`](/docs/commands/block), укажите базовую точку и выберите символ и атрибуты в том порядке, в каком команда ВСТАВИТЬ должна их запрашивать. Каждая вставка блока командой [`ВСТАВИТЬ`](/docs/commands/insert) затем запрашивает значение каждого атрибута, предлагая значение по умолчанию.

### Чем отличаются тег, подсказка и значение по умолчанию?

Тег — имя атрибута, его идентификатор: его показывает определение, и им подписано поле в окне команды [`АТРЕДАКТ`](/docs/commands/eattedit). Подсказка — вопрос, которым команда ВСТАВИТЬ запрашивает значение. Значение по умолчанию — предлагаемое значение, которое принимает Enter.

### Как отредактировать определение атрибута?

Дважды щелкните его, пока оно не вошло в блок: команда [`ТЕКСТРЕД`](/docs/commands/textedit) открывает его тег, подсказку и значение по умолчанию. Когда атрибут уже в блоке, значения каждого вхождения правятся командой [`АТРЕД`](/docs/commands/attedit) или [`АТРЕДАКТ`](/docs/commands/eattedit).
