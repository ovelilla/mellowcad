STYLE 管理圖面的文字型式：文字以什麼樣式書寫。每個文字、多行文字與屬性都有一個型式，新建的物件使用目前的型式，新圖面中為 Standard。AutoCAD 的 STYLE 會開啟「文字型式」對話方塊；MellowCAD 尚未提供此對話方塊，因此 STYLE 會開啟「型式」選項板的文字表格，[`DIMSTYLE`](/docs/commands/dimstyle) 的標註型式也在此選項板中。在指令之前所做的選取會被捨棄，與對話方塊相同；在指令執行中加上單引號輸入 `'STYLE`，可以開啟選項板而不結束該指令。

表格列出各個型式，並標示目前的型式。「新建」複製所選的型式，以第一個未使用的名稱 `style1`、`style2`… 命名，並將它設為目前的型式。「設為目前的」將型式設為目前的型式；型式名稱可以重新輸入，已使用的名稱（不分大小寫）會被拒絕，與 AutoCAD 相同。「刪除」移除型式，但不能刪除 Standard、目前的型式或使用中的型式。「高度」為型式指定固定高度：預設值 0 表示不固定，因此 [`TEXT`](/docs/commands/text) 每次都會要求高度；設定高度後，TEXT 就不會再要求。每次變更都是一個步驟，`U` 可以將它退回。選取文字時，「性質」選項板的「文字型式」列可以一個步驟將它們改為其他型式。

- **指令：** `STYLE`
- **快捷鍵：** `ST`, `DDSTYLE`
- **面板：** [註解](/docs/commands#annotate)
- **試試看：** [開啟編輯器](/zh-tw/draw)，輸入 `ST` 並按 Enter。

## 尚未支援的功能 [#missing]

「文字型式」對話方塊及其預覽：STYLE 改為開啟「型式」選項板。字體、字體型式與大字體、寬度係數、傾斜角度，以及「上下顛倒」、「左右反向」與「垂直」效果：每個型式都以 Arial 繪製，直立，寬度為 1。可註解型式，以及新的 AutoCAD 圖面中與 Standard 並列的 Annotative 型式。在指令行詢問所有設定的 `-STYLE`。

## 常見問題 [#questions]

### AutoCAD 文字型式（STYLE）的快捷鍵是什麼？

`ST`，然後按 Enter 或空白鍵；也可以使用 `DDSTYLE`。在任何語言版本的 AutoCAD 中都可以使用 `_STYLE`。

### CAD 如何變更文字型式？

對於新文字，請在 STYLE 開啟的「型式」選項板中將型式設為目前的，或使用 [`TEXT`](/docs/commands/text) 的 `Style` 選項。對於已寫好的文字，請選取文字，再在「性質」選項板的「文字型式」列選擇型式。

### 如何變更文字型式的字體？

在 AutoCAD 中，於「文字型式」對話方塊的「字體名稱」變更。此處尚未提供：每個型式都以 Arial 繪製，型式之間只有名稱與高度不同。

### TEXT 為什麼不要求高度？

目前的型式有自己的高度。在「型式」選項板中將其高度設為 0，[`TEXT`](/docs/commands/text) 就會再次要求高度，並以上次使用的高度作為預設值。
