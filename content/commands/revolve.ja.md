REVOLVE[回転ソリッド]コマンドは、閉じた 2D の断面を軸の周りに回転させて 3D ソリッドを作成します。1 辺が軸上にある長方形からは円柱が、軸の横にある円からはリングができます。断面(円、楕円、閉じたポリラインやスプライン、リージョン)を選択して[Enter]を押し、軸を 2 点またはオプションのいずれかで指定してから角度を指定します。[Enter]で 1 回転します。各断面は現在の画層のソリッドになり、DELOBJ の既定どおり削除されます。コマンド全体が 1 回の操作で元に戻せます。

軸は断面と同じ平面上にあり、断面全体が軸の片側になければなりません。そうでないと、角度を尋ねる前に <Message id="revolveOneSide" /> と表示されてコマンドが終了します。角度は軸の 1 点目から 2 点目への向きについて右手の法則で回転し、負の角度は逆向きに回転します。MellowCAD の 3D はソリッドのみで、まだ部分的な対応です。AutoCAD ではサーフェスになる開いた断面は受け付けません。

## Options

### MOde

<Command id="EXTRUDE" /> と同様に、<Keyword id="SOlid" /> か <Keyword id="SUrface" /> かを尋ねます。サーフェス オブジェクトがまだないため、既定の <Keyword id="SOlid" /> だけを受け付けます。

### Object

軸のプロンプトの既定値なので、[Enter]で選択されます。線分、ポリライン、円弧、スプラインを選択すると、その両端を結ぶ直線が軸になり、クリックした位置に近い方の端点が始点になります。閉じたオブジェクトには端点がないため、<Message id="revolveClosedAxis" /> と表示されてコマンドが終了します。

### X

UCS の原点を通る X 軸です。

### Y

UCS の原点を通る Y 軸です。このセッションのように Y 軸の右側に描いた断面は、Y 軸に沿って横たわる部品になります。

### Z

UCS の原点を通る Z 軸です。UCS の XY 平面上の断面は Z 軸に直交するため、REVOLVE は <Message id="revolvePerpendicular" /> と表示して終了します。Z は立てて描いた断面に使います。

### STart

角度のプロンプトで、回転を始める角度を指定します。既定値は常に 0 です。断面をまずその角度まで回転させてから、角度を再び尋ねます。

### Reverse

軸の向きを反転して角度を逆向きにし、角度を再び尋ねます。

### EXpression

<Command id="EXTRUDE" /> と同様に、角度を算術式で指定します。

## Missing

断面の平面上にない軸はサポートされません。AutoCAD ではこの場合、断面がサーフェスとして回転されますが、ここでは REVOLVE が <Message id="revolveUnable" /> と表示して終了します。楕円弧やソリッドのエッジをオブジェクトの軸にすることはできません。サーフェス オブジェクトがまだないため、SUrface モードと開いた断面もありません。角度を指定する間、プレビューはカーソルに合わせて回転せず、1 回転全体が表示されます。回転ソリッドの <Command id="EXPLODE" />(AutoCAD ではサーフェスとリージョンになります)、グリップ、プロパティ パレットでの角度の編集もありません。

## Questions

### AutoCAD の REVOLVE の短縮コマンドは?

`REV` と入力し、[Enter]または[Space]を押します。コマンド名を入力しても実行でき、AutoCAD のどの言語版でも `_REVOLVE` が使えます。

### AutoCAD で断面を軸の周りに回転させて 3D にするには?

断面の半分を、軸の線の横に 1 つの閉じたオブジェクト(閉じたポリラインかリージョン)として描きます。REVOLVE を実行して断面を選択し、[Enter]を押します。もう一度[Enter]を押して <Keyword id="Object" /> を選び、軸の線を選択するか、軸の両端を指定します。最後に[Enter]で 1 回転させます。

### AutoCAD の REVOLVE ができないのはなぜ?

多くの場合、軸が断面を横切っています。REVOLVE は <Message id="revolveOneSide" /> と表示して終了します。軸を断面の辺上か、その外側に移動してください。軸上にある辺はかまいません。断面の平面に直交する軸では <Message id="revolvePerpendicular" /> と表示されます。MellowCAD にはまだサーフェスがないため、開いた断面は受け付けません。

### 1 回転ではなく一部だけ回転させるには?

角度のプロンプトで 90 や 270 などの角度を入力します。<Keyword id="STart" /> で回転の開始位置をずらし、<Keyword id="Reverse" /> で逆向きに回転させます。
