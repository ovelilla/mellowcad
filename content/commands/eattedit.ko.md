EATTEDIT(속성 편집) 명령은 블록 참조 하나에 대해 AutoCAD의 고급 속성 편집기를 엽니다. 블록을 선택하라고 묻고, 편집기의 속성 탭처럼 각 속성마다 태그를 이름으로 하고 값이 채워진 필드를 보여 줍니다. 값을 다시 입력하고 Tab 키로 필드 사이를 이동하며, Enter 키를 누르면 한 단계로 적용되어 <Command id="U" />로 되돌릴 수 있습니다. Esc 키를 누르면 아무것도 바뀌지 않습니다.

속성이 있는 참조를 더블클릭하면 AutoCAD처럼 EATTEDIT이 실행됩니다. 명령행에는 더블클릭한 점을 답으로 하여 명령이 기록되고, 상자가 바로 열립니다. 선택은 선택 상자 아래의 객체를 집습니다. 블록 참조가 아닌 객체와 속성이 없는 블록은 거부되고 다시 묻습니다. 바뀌는 것은 선택한 참조뿐이며, 블록 정의와 다른 참조는 각자의 값을 유지합니다.

## Missing

편집기의 문자 옵션 탭(각 속성 문자의 스타일, 자리맞추기, 높이, 회전, 폭 비율 등)과 특성 탭(도면층, 선종류, 색상, 선가중치), 블록 선택 버튼이 없습니다. 속성 하나를 제자리에서 편집하는 ATTIPEDIT과 그 Ctrl+더블클릭도 없습니다. 참조에서 잠기지 않은 속성 자체의 그립과 특성 팔레트의 속성 행, `-ATTEDIT`도 없습니다.

## Questions

### AutoCAD에서 고급 속성 편집기를 여는 방법은?

속성이 있는 블록 참조를 더블클릭하거나, `EATTEDIT`을 입력하고 블록을 클릭합니다. AutoCAD의 어느 언어 버전에서나 `_EATTEDIT`을 쓸 수 있습니다.

### AutoCAD에서 속성 값을 바꾸려면?

블록을 더블클릭하고, 속성 필드에 새 값을 입력한 다음 Enter 키를 누릅니다. 참조마다 값을 따로 가지므로, 하나를 바꿔도 나머지는 그대로입니다.

### 블록을 더블클릭해도 속성 편집이 안 될 때는?

EATTEDIT은 블록에 속성이 있는 참조에만 열리며, 속성 없이 만든 블록에는 속성이 없습니다. <Command id="ATTDEF" />로 속성을 정의하고, 블록을 만들 때 다른 객체와 함께 선택합니다. 속성 값이 보이지 않으면 <Command id="ATTDISP" />를 확인합니다. 이 명령은 숨김 속성이나 모든 속성을 숨길 수 있습니다.

### EATTEDIT과 ATTEDIT의 차이는?

편집하는 값은 같습니다. EATTEDIT은 고급 속성 편집기의 속성 탭처럼 각 필드를 태그로 표시하고, <Command id="ATTEDIT" />은 속성 편집 대화상자처럼 프롬프트로 표시합니다. AutoCAD의 EATTEDIT은 각 속성의 문자 옵션과 특성도 편집합니다.
