ID（點位置）指令顯示一點的座標。在 `Specify point:` 提示下點選、鎖點或輸入該點，ID 會在指令行中以一行顯示其 X、Y 與 Z，然後結束。數值以目前的 UCS 表示，精確度為圖面的精確度。使用物件鎖點時，Z 是物件在該點的高度；否則為高程平面的 Z。按 Enter 會不顯示任何訊息而結束，在 ID 之前選取的物件會在指令開始時取消選取。以撇號輸入 `'ID`，可在另一個指令中執行，該指令隨後繼續。

## Questions

### AutoCAD 的 ID 指令有什麼作用？

顯示一點的位置：目前 UCS 中的 X、Y 與 Z。不繪製也不變更任何物件。

### CAD 如何查詢一點的座標？

輸入 `ID`，然後以物件鎖點（端點或中心點）按一下該點，使其準確落在點上。座標會顯示在指令行中。

### 如何查詢一點的 Z 座標？

以物件鎖點鎖定該點：ID 會顯示物件在該點的 Z。直接按一下則得到高程平面的 Z，除非以 ELEVATION 或 UCS 提高，否則為 0。

### 為什麼 ID 顯示的座標與預期不同？

ID 以目前的 UCS 讀取座標。如果 UCS 已移動或旋轉，數值會從其原點、沿其軸量測：以 <Command id="UCS" /> 的「世界」選項切換回世界座標即可讀取世界座標。
