Команда ФАСКАКРОМКИ (CHAMFEREDGE) снимает фаски с кромок 3D-тела. Она сообщает два текущих расстояния, затем запрашивает кромку и, после первой, другие на той же грани, пока не будет нажат Enter: щелчок берет кромку под курсором, введенная точка — кромку, проходящую через нее. На кромку, у которой нет общей грани с первыми, команда отвечает <Message id="edgesOneFace" />, на кромку другого тела — <Message id="chamferMultipleBodies" />. По мере выбора кромок тело рисуется таким, каким оно станет. После Enter команда просит нажать Enter еще раз, чтобы принять фаску, или изменить расстояния для этой фаски; второй Enter и строит ее.

Первое расстояние откладывается вдоль грани, общей для кромок; для одиночной кромки — вдоль грани, которую берет AutoCAD: передней для верхней передней кромки ящика и верхней для края цилиндра. Прямая кромка между двумя плоскими гранями становится плоской полосой, круглая кромка отверстия или края — полосой конуса, а фаски, сходящиеся в углу, соединяются по линии. В следующий раз эти расстояния снова предлагаются по умолчанию. Тело сохраняет свой слой и свойства, но теряет то, из чего было построено: ящик больше не ящик. Вся команда — один шаг отмены. 3D в MellowCAD — это только 3D-тела, и пока оно реализовано частично.

## Options

### Loop

Берет все кромки вокруг грани: выберите одну кромку, затем <Keyword id="Accept" /> для показанного контура или <Keyword id="Next" /> для контура другой грани, к которой принадлежит кромка. <Keyword id="Edge" /> возвращает к выбору отдельных кромок.

### Distance

Запрашивает первое расстояние, затем второе — каждое числом или как расстояние между двумя точками; на 0 и отрицательные значения команда отвечает <Message id="distanceTooSmall" />. Параметр <Keyword id="Expression" /> позволяет задать значение формулой. В запросе принятия команда запрашивает длину фаски базовой поверхности и другой поверхности — только для этой фаски.

## Missing

Угол, где сходятся три кромки с фасками. Прямая кромка рядом с криволинейной гранью, круглая кромка не на оси своего цилиндра и любая кромка сферы, тора, тела выдавливания или вращения: здесь на них возникает ошибка моделирования. Две ручки-стрелки, которые AutoCAD показывает в запросе принятия, по одной на каждое расстояние. Выбор кромки тела в команде <Command id="CHAMFER" />, который AutoCAD тоже допускает. Показ фаски сетью во время выбора и поверхности.

## Questions

### Как снять фаску с кромки 3D-тела в AutoCAD?

Запустите команду ФАСКАКРОМКИ, выберите <Keyword id="Distance" /> и задайте оба расстояния, выберите кромки одной грани, затем дважды нажмите Enter: первый раз, чтобы закончить выбор, второй — чтобы принять. `6` и `6` из примера срезают две верхние кромки ящика.

### Почему команда ФАСКАКРОМКИ сообщает, что кромки должны принадлежать одной грани?

Кромки одной фаски имеют общую грань: вдоль нее откладывается первое расстояние. Кромки другой грани обработайте повторным запуском команды.

### Почему команда ФАСКА не работает с 3D-телом?

В AutoCAD команда <Command id="CHAMFER" /> снимает фаску и с кромки тела, а в MellowCAD пока нет: используйте команду ФАСКАКРОМКИ, а для скругления кромки — <Command id="FILLETEDGE" />.

### Как снять фаску с кромки отверстия?

Выберите его круглую кромку там, где она встречается с плоской гранью: фаска получается полосой конуса вокруг отверстия.
