ФАСКАКРОМКИ (CHAMFEREDGE) снимает фаски с кромок 3D-тела. Команда сообщает две текущие длины, затем запрашивает кромку и, после первой, другие на той же грани, пока не будет нажат Enter: щелчок берет кромку под курсором, введенная точка — кромку, проходящую через нее. На кромку, у которой нет общей грани с первыми, команда отвечает <Message id="edgesOneFace" />, на кромку другого тела — <Message id="chamferMultipleBodies" />. По мере выбора кромок тело рисуется таким, каким оно станет. Затем Enter просит нажать Enter еще раз, чтобы принять, или изменить длины для этой фаски; этот Enter и строит ее.

Первая длина откладывается вдоль грани, общей для кромок; для одиночной кромки — вдоль грани, которую берет AutoCAD: передней для верхней передней кромки ящика и верхней для края цилиндра. Прямая кромка между двумя плоскими гранями становится плоской полосой, круглая кромка отверстия или края — полосой конуса, а фаски, сходящиеся в углу, соединяются по линии. Длины снова предлагаются в следующий раз. Тело сохраняет свой слой и свойства, но теряет то, из чего было построено: ящик больше не ящик. Вся команда — один шаг отмены. 3D в MellowCAD — это только 3D-тела, и пока частично.

## Options

### Loop

Берет все кромки вокруг грани: выберите одну кромку, затем <Keyword id="Accept" /> для показанного контура или <Keyword id="Next" /> для контура другой грани, к которой принадлежит кромка. <Keyword id="Edge" /> возвращает к выбору отдельных кромок.

### Distance

Запрашивает первую длину, затем вторую, каждую введенную или как расстояние между двумя точками; на 0 и меньше команда отвечает <Message id="distanceTooSmall" />. <Keyword id="Expression" /> принимает длину в виде формулы. В запросе принятия команда запрашивает длину для базовой поверхности и для другой поверхности, только для этой фаски.

## Missing

Угол, где сходятся три кромки с фасками. Прямая кромка рядом с криволинейной гранью, круглая кромка не на оси своего цилиндра и любая кромка сферы, тора, тела выдавливания или вращения: здесь они завершаются ошибкой моделирования. Две ручки-стрелки, которые AutoCAD показывает в запросе принятия, по одной на длину. Выбор кромки тела в <Command id="CHAMFER" />, который AutoCAD тоже допускает. Фаска, рисуемая сетью во время выбора, и поверхности.

## Questions

### Как снять фаску с кромки 3D-тела в AutoCAD?

Запустите ФАСКАКРОМКИ, выберите <Keyword id="Distance" /> и задайте обе длины, выберите кромки одной грани, затем дважды нажмите Enter: первый раз, чтобы закончить выбор, второй — чтобы принять. `6` и `6` из примера срезают две верхние кромки ящика.

### Почему ФАСКАКРОМКИ пишет, что кромки должны принадлежать одной грани?

Кромки одной фаски имеют общую грань: вдоль нее откладывается первая длина. Кромки другой грани обработайте во втором запуске.

### Почему ФАСКА не работает с 3D-телом?

<Command id="CHAMFER" /> в AutoCAD тоже снимает фаску с кромки тела, а в MellowCAD пока нет: используйте ФАСКАКРОМКИ, а для скругления кромки — <Command id="FILLETEDGE" />.

### Как снять фаску с кромки отверстия?

Выберите его круглую кромку там, где она встречается с плоской гранью: фаска — полоса конуса вокруг отверстия.
