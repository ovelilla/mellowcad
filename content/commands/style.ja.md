STYLE[文字スタイル管理]コマンドは、図面の文字スタイル、つまり文字を何で書くかを管理します。文字、マルチ テキスト、属性はそれぞれスタイルを持ち、新しいものには現在のスタイルが適用されます。新しい図面では Standard です。STYLE は AutoCAD と同様に[文字スタイル管理]ダイアログを開きます。ダイアログと同様に、実行前の選択は解除されます。コマンドの実行中にアポストロフィを付けて `'STYLE` と入力すると、そのコマンドを終了せずに開き、ダイアログを閉じるとそのコマンドが続行します。

ダイアログには現在のスタイルが表示され、スタイルが一覧表示されます。一覧は[すべてのスタイル]または[使用中のスタイル]だけにできます。[新規作成...]は名前を尋ね、空いている最初の名前 `style1`、`style2`… を提示して、選択したスタイルのコピーを作成し、現在のスタイルにします。[現在に設定]は選択したスタイルを現在のスタイルにします。[F2]でその名前を編集できます。AutoCAD と同様に、大文字・小文字を問わず、すでに使われている名前は受け付けられません。[削除]はスタイルを削除しますが、Standard、現在のスタイル、使用中のスタイルは削除できません。[高さ]はスタイルに固定の高さを与え、[適用]で反映されます。既定の 0 では高さが固定されず、<Command id="TEXT" /> が毎回高さを尋ねます。高さを設定すると、TEXT は尋ねません。[キャンセル]は適用していない高さを破棄し、何かを変更すると[閉じる]に変わります。ダイアログで行ったすべての操作は 1 回の操作で、<Command id="U" /> で元に戻せます。文字を選択している場合は、プロパティ パレットの[文字スタイル]の行で、1 回の操作で別のスタイルを適用できます。

## Missing

ダイアログのプレビューはありません。フォント、フォント スタイル、ビッグフォント、幅係数、傾斜角度、[上下反転]、[左右反転]、[縦書き]の効果もありません。どのスタイルも Arial で、傾きなし、幅 1 で描かれます。異尺度対応スタイルと、AutoCAD の新しい図面に Standard とともに含まれる Annotative スタイルもありません。すべてをコマンド ラインで尋ねる `-STYLE` もありません。

## Questions

### AutoCAD の STYLE の短縮コマンドは?

`ST` と入力し、[Enter]または[Space]を押します。`DDSTYLE` も使えます。`_STYLE` は AutoCAD のどの言語版でも使えます。

### AutoCAD で文字スタイルを変更するには?

新しい文字には、STYLE で開くダイアログの[現在に設定]、または <Command id="TEXT" /> の <Keyword command="TEXT" id="Style" /> オプションでスタイルを現在のスタイルにします。記入済みの文字は、選択してプロパティ パレットの[文字スタイル]の行でスタイルを選びます。

### 文字スタイルのフォントを変更するには?

AutoCAD では[文字スタイル管理]ダイアログの[フォント名]で変更します。ここではまだできません。どのスタイルも Arial で描かれ、スタイルの違いは名前と高さだけです。

### TEXT で高さを聞かれないのはなぜ?

現在の文字スタイルに固定の高さが設定されています。[文字スタイル管理]ダイアログでその高さを 0 にして[適用]を押すと、<Command id="TEXT" /> が再び高さを尋ね、前回の高さを既定値として表示します。
