CHPROP(특성 변경) 명령은 선택한 객체의 특성을 명령행에서 바꿉니다. 특성 팔레트의 일반 행을 프롬프트로 묻는 것입니다. 객체를 선택하거나 명령 전에 선택한 다음, 바꿀 특성을 고릅니다. 하나를 바꿀 때마다 다시 묻고, Enter 키로 끝납니다. 각 특성의 프롬프트는 선택 세트의 값을 기본값으로 제시하며, 객체마다 다르면 <Message id="varies" /> 값을 제시하고, 거기서 Enter 키를 누르면 각 객체가 자기 값을 유지합니다. 설정한 값은 명령이 끝날 때 적용되므로, Esc 키를 누르면 모든 객체가 그대로 남습니다. 잠긴 도면층의 객체는 개수에 들어가지만 제외되며, 각각 <Message id="objectOnLockedLayer" /> 메시지를 표시합니다. 실행 전체가 <Command id="U" /> 명령으로 되돌릴 수 있는 한 단계입니다.

## Options

### Color

1부터 255까지의 색상 번호, `red` 같은 이름, `BYLAYER`, 또는 <Keyword id="Truecolor" /> 옵션과 그 `Red,Green,Blue` 값으로, <Command id="COLOR" /> 명령이 받는 형식과 같습니다. COLOR가 거부하는 값은 여기서도 거부되고 다시 묻습니다.

### LAyer

도면층 이름이며 대소문자는 상관없습니다. 도면층 이름이 될 수 없는 이름은 <Message id="invalidLayerName" /> 메시지를, 도면에 없는 이름은 찾을 수 없다고 표시하며, 둘 다 다시 묻습니다. CHPROP은 도면층을 만들지 않습니다.

### LType

선종류 이름이며 대소문자는 상관없습니다. `ByLayer`도 됩니다. 도면에 로드되지 않은 선종류는 AutoCAD의 인치 단위 파일인 acad.lin에서 로드합니다. AutoCAD도 미터법 도면에서조차 그렇게 합니다. 그 파일에도 없는 이름은 찾을 수 없다고 표시하고 특성 프롬프트로 돌아갑니다.

### ltScale

객체 자체의 선종류 축척으로, 그 객체에 대해서만 <Command id="LTSCALE" /> 값에 곱해집니다. 입력하거나 두 점으로 잰 거리이며, 음수는 그 크기로 처리되고, 0은 <Message id="valueMustBeNonzero" /> 메시지를 표시하고 다시 묻습니다.

### LWeight

밀리미터 단위의 선가중치로, <Command id="LWEIGHT" /> 명령처럼 가장 가까운 표준 값으로 반올림됩니다. `ByLayer`도 됩니다. `?`는 표준 값을 나열합니다.

### Thickness

입력하거나 두 점으로 잰 거리이며, 음수와 0도 됩니다. 선택 세트의 선, 원, 호, 폴리선에 각각의 법선 방향으로 설정됩니다. 다른 유형의 객체는 명령이 끝날 때 두께를 바꿀 수 없다고 표시합니다.

## Missing

여기서는 객체에 투명도, 재료, 주석이 없으므로 프롬프트에 나열되지 않습니다. 색상, 선종류, 선가중치의 ByBlock과 선가중치의 기본값이 없습니다. 색상표가 없습니다. 문자와 속성 정의의 두께는 그대로 남습니다. 특성 옵션이 같은 프롬프트를 고도와 함께 묻는 CHANGE가 없습니다.

## Questions

### 오토캐드 특성 변경(CHPROP) 단축키가 있습니까?

단축키는 없습니다. `CHPROP`을 입력하거나, AutoCAD의 어느 언어 버전에서든 `_CHPROP`을 입력합니다. 명령 프롬프트에서 Enter 키를 누르면 반복됩니다.

### CHPROP과 PROPERTIES의 차이는 무엇입니까?

바꾸는 특성은 같습니다. <Command id="PROPERTIES" /> 명령은 특성을 팔레트에 각 객체의 형상과 함께 표시하고, CHPROP은 명령행에서 물으므로 손을 키보드에서 떼지 않아도 됩니다.

### 명령행에서 객체의 색상을 바꾸려면 어떻게 합니까?

`CHPROP`을 입력하고 객체를 선택한 다음 Enter 키를 누르고, <Keyword id="Color" /> 옵션을 선택하여 빨간색이면 `1`처럼 색상을 입력합니다. Enter 키를 한 번 더 눌러 끝냅니다.

### 여러 객체를 다른 도면층으로 옮기려면 어떻게 합니까?

CHPROP을 실행하고 객체를 선택한 다음 <Keyword id="LAyer" /> 옵션을 선택하고 도면층 이름을 입력합니다. 도면층이 있어야 하므로, 먼저 <Command id="LAYER" /> 명령에서 만듭니다.
