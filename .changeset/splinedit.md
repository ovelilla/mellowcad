SPLINEDIT (SPE) edits a spline as AutoCAD 2027 does: Close / Open, Join, Fit data (Add, Close / Open, Delete, Move, Purge, Tangents), Edit vertex (Add, Delete, Elevate order up to 26, Move, Weight), convert to Polyline, Reverse and an Undo of its own per step, each run one undo step. The editor's rail gains Edit Spline in the Modify panel.
