ARRAYRECT's Levels, as AutoCAD 2027 asks them: the number of levels and their distance or Total, stacked along the UCS's Z on top of each row's elevation, spaced by default one and a half times the set's rise. `RectangularArray` gains the required `levels` and `levelSpacing`; the palette shows Levels and Level spacing (`arrayLevels`, `arrayLevelSpacing`) and LIST lists them. Drawing file version 41: an older file's rectangular array reads as one level, 1 apart.
