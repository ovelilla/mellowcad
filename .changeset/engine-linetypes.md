A drawing's own linetypes, a table as AutoCAD's LTYPE: each with its description, its lengths as AutoCAD defines them and a complex one's text and shapes (`Linetype`, `LinetypeElement`, `LinetypeText`, `LinetypeShape`), saved in the drawing (file version 53) and opened and saved in a DXF of R12 to 2018; a complex linetype's text is drawn along the object as AutoCAD 2027 plots it (its shapes are not). The six every drawing holds are named as acadiso.lin names them (`DASHED`, `HIDDEN`, `CENTER`, `PHANTOM`, `DASHDOT`), and a file of an older version opens with them. -LINETYPE gains Load (acadiso.lin's 59 linetypes or acad.lin's, in inches), Set loads a linetype acadiso.lin has, and `?` asks for the file to list; PURGE gains LTypes; CHPROP gains ltScale, and its LType loads from acad.lin. An object's own linetype scale (`linetypeScale`, DXF 48), set by CHPROP, the Properties palette's Linetype scale row (`EntityProperty` `"linetypeScale"`) and CELTSCALE (`DocumentSettings.currentLinetypeScale`). `EngineState.linetypes` lists the drawing's linetypes for the drop-downs, `linetypeDashes` lays a pattern as a stroke draws it, and `DocumentReader` gains `getLinetypes`, `getLinetype`, `linetypeLookup` and `canRemoveLinetype`. Breaking: `LinetypeDef` is now `Linetype` (`name`, `description`, `pattern` with AutoCAD's signed lengths), and `EngineNames.linetypes` and the catalog's `interface.linetype` are gone: a linetype is shown by its name. New catalog keys: `commands.keywords` CHPROP's `ltScale`, LINETYPE's `Load`, `Yes` and `No`, PURGE's `LTypes`; `commands.prompts` `newLinetypeScale`, `linetypeFileToList`, `linetypesToLoad`, `linetypeFileToSearch`, `reloadLinetype`, `purgeLinetype`; `commands.promptForms` `purgeLinetype`, `reloadLinetype`; `commands.messages` `linetypeLoaded`, `linetypeReloaded`, `noLinetypesInFile`, `cantFindFile`, `deletingLinetype`, `linetypesDeleted`, `noUnreferencedLinetypes`; `interface.property.row.linetypeScale`.
