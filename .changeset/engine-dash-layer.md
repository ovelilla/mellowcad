-LAYER (`-LA`), the command line's layer table, as AutoCAD 2027's console asks it in every command language: `?` lists the layers in AutoCAD's columns, Make, Set (a name, or the layer of an object picked), New, Rename, ON, OFF, LOck and Unlock (names with wildcards, or the objects selected), Color (a negative one turning the layers off, or Truecolor), Ltype (loaded from acad.lin if the drawing lacks it) and LWeight, and DELete; typed transparently too. A run is one undo step, which the next -LAYER run joins under UNDO's Layer, as AutoCAD folds them. `DocumentReader` gains `canRemoveLayer`. New catalog keys: `commands.names` and `commands.keywords` `-LAYER`, `commands.keywordLabels` `-LAYER`, `commands.prompts` `layerNamesToList`, `layerToMake`, `layerToSet`, `layerSelectObject`, `newLayerNames`, `oldLayerName`, `renamedLayerName`, `layersToTurnOn`, `layersToTurnOff`, `layersToLock`, `layersToUnlock`, `layerSelectObjects`, `currentLayerOff`, `currentLayerOffNo`, `layerColor`, `layersForColor`, `layerLinetype`, `layersForLinetype`, `layerLineweight`, `layersForLineweight`, `layersToDelete`; `commands.promptForms` `currentLayerOff`; `commands.promptTails` `layerColor` (English's first tail: an empty one, AutoCAD's space before the colon); `commands.messages` `currentLayerName`, `layerListColumns`, `layerOn`, `layerOff`, `layerLockedFlag`, `layerPlotsFlag`, `layerListCurrent`, `noMatchingLayerNames`, `layerAlreadyExists`, `invalidLayerNameQuoted`, `cannotRenameLayer`, `layerNameInUse`, `layersNotDeleted`, `layerNoObjectFound`, `layerMadeCurrent`, `invalidColor`, `layerLoadedLinetypes`, `layerLinetypeNotFound`; `interface.tool.dashlayer`.
